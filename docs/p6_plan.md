# P6 계획서 — 포트폴리오 운영 연구 (코어·위성·대기 자금·수익 적립)

> 목적: 신호 전략(P5)이 QQQ를 확실히 이기지 못한다는 결과를 받아들이고, **돈을 어디에 얼마나 나눠 두고 어떻게 옮길지**로 세후 성과와 낙폭을 개선할 수 있는지 숫자로 확인한다.
> 원칙: 후보와 판정 기준은 결과를 보기 전에 사전 등록한다. 결과를 본 뒤 후보를 늘리거나 기준을 바꾸지 않는다. 검증 구간(2022년~)은 최종 후보 1개에만 한 번 연다.

---

## 1. P5에서 이어받는 사실

| 사실 | 근거 |
| --- | --- |
| 수익의 대부분은 쉬는 돈을 넣어 둔 QQQM에서 나왔다 | P5-3 기여 분해 (QQQM 1억 4,270만 원 vs 신호 종목 3,280만 원) |
| 신호 종목 선택은 무작위 수준이다 (B0.5, 2016~2021) | P5-5 무작위 진입 48백분위, QQQ 대비 +0.01%p |
| QQQM을 자주 사고팔아 생긴 세금·비용이 성과를 깎았다 | P5-5 2019년 QQQM 매매 231회, P5-1.1 QQQM 매매 양도세 약 800만 원 |
| 무료 데이터로는 2015년 이전 종목 검증이 불가능하다 | P5-5 연도별 누락 33.7~45.8% |
| QQQ 자체는 1999년부터 빠짐없는 데이터가 있다 | 종목 선택이 없는 조합은 생존 편향 없이 2000·2008년 폭락 포함 시험 가능 |

## 2. 데이터와 기간

| 항목 | 내용 |
| --- | --- |
| QQQ | 1999-03-10 ~, 배당 포함 (세후 재투자) |
| 단기 국채 (대기 자금) | FRED `DTB3`(3개월 국채 수익률)로 일별 수익 계산. SGOV·BIL은 비교 확인용 |
| QLD (2배 레버리지) | 2006-06 이후 실제 데이터. 이전은 QQQ 일간 수익 × 2 − 연 보수 0.95% − 차입 비용(DTB3)으로 합성하고, 겹치는 기간(2006~2021) 실제 QLD와의 차이를 보고 |
| 환율 | FRED `DEXKOUS` + yfinance `KRW=X` (P5-5와 같은 방식) |
| 신호 위성 | P5의 B0.5 엔진 그대로 (파라미터 변경 없음). 데이터 신뢰 구간인 **2016~2021년에만** 사용 |
| 학습 구간 | 종목 없는 조합: **1999-03 ~ 2021-12** / 위성 포함 조합: **2016-01 ~ 2021-12** |
| 하위 구간 | 1999~2007 (닷컴 붕괴), 2008~2015 (금융위기·회복), 2016~2021 |
| 검증 구간 | 2022-01 ~ 최신, 봉인 (P6-4에서 최종 1개만 1회) |
| 초기 자금 | 4,000만 원, 추가 납입 없음 (P6-3에서 월 납입 변형 검토) |

## 3. 비용·세금 모형

- 매매 수수료 0.07%, 환전 스프레드 0.1% (P5와 같음)
- 해외 주식 양도세: 연간 실현 손익에서 250만 원 공제 후 22%, 취득가는 **이동평균법**
- 배당 원천징수 15% 후 재투자
- 모든 기간에 지금 세법을 똑같이 적용 (과거 실제 세법 아님)
- 세후 (a) = 기간 끝 전량 매도·세금 납부, 세후 (b) = 미청산 평가 (P5와 같은 정의)

## 4. 후보 (사전 등록 대상)

| 번호 | 구성 | 규칙 | 구간 |
| --- | --- | --- | --- |
| **P0** | QQQM 100% | 사서 보유 | 전 기간 (기준) |
| P3 | 코어 60% + 대기 40% | 대기 자금은 단기 국채. QQQ가 직전 최고점 대비 −20/−30/−40%에 도달하면 대기 자금의 1/3씩 코어로. QQQ가 직전 최고점을 회복하면 60:40으로 한 번 재조정 | 1999~2021 |
| P4 | 코어 100% ↔ 60% | QQQ 종가가 200일선 아래면 다음 날 코어의 40%를 단기 국채로, 위로 돌아오면 다시 코어로 | 1999~2021 |
| P5 | P3 + 레버리지 | P3 규칙에 더해, 대기 자금 투입 후 QQQ가 200일선을 다시 넘으면 총자산의 최대 20%를 QLD로. QQQ가 200일선을 다시 깨거나 직전 최고점을 회복하면 QLD 청산 | 1999~2021 |
| P1 | 코어 70% + 위성 30% | 코어는 팔지 않음. 위성 = B0.5, 위성의 쉬는 돈은 단기 국채 | 2016~2021 |
| P2 | 코어 34% + 위성 33% + 대기 33% | P1 위성 + P3 대기 자금 규칙 | 2016~2021 |
| R0 | 코어 25% + 위성 75%, 매년 재조정 | 연말에 25:75로 **양방향** 재조정 (위성 손실 시 코어를 팔아 채움) | 2016~2021 |
| **R1** | 코어 25% + 위성 75%, 수익 적립 | 코어는 팔지 않음. 점검일에 위성 평가액이 기준액(3,000만 원) + X를 넘으면 초과분을 **현금으로** QQQM에 옮김. 손실은 채우지 않음. 위성이 2,000만 원 아래면 신규 매수 중단 | 2016~2021 |

### R1 주 설정과 주변값

- **주 설정 (사전 등록)**: X = 300만 원, 분기 말 점검, 위성 쉬는 돈 = 단기 국채
- 주변값: X = 100 / 300 / 500만 원 × 점검 = 매월 / 분기 / 연말(250만 원 공제에 맞춤) × 쉬는 돈 = QQQM / 단기 국채 / 현금
- 주 설정은 **바로 옆 주변값(X 한 칸, 점검 주기 한 칸)과 세후 (a) 차이가 1%p 이내**일 때만 "안정"으로 본다. 최고값을 고르지 않는다.

### 주변값 (종목 없는 조합)

- P3·P5 투입 단계: −15/−25/−35%, −20/−30/−40%(주), −25/−35/−45%
- P4·P5 이동평균: 190 / 200(주) / 210일

## 5. 판정 기준 (사전 등록)

두 등급을 모두 등록하고, **어느 등급을 목표로 할지는 P6-1 결과를 보기 전에** 사용자가 정해 사전 등록 파일에 적는다. 정하지 않으면 두 등급 모두 판정하고 둘 다 보고한다.

| 등급 | 조건 (학습 구간 전체, 세후 (a) 기준) |
| --- | --- |
| **공격형 합격** | QQQ 대비 +2%p 이상 · MDD가 QQQ 이하 |
| **안정형 합격** | QQQ 대비 −1.5%p 이내 · MDD가 QQQ의 70% 이하 · 원금 회복 기간이 QQQ 이하 |
| 공통 조건 | 하위 구간 3개 중 2개 이상에서 같은 등급 조건 충족 (위성 조합은 2016~2021 연도별 표로 대신) · 주 설정이 주변값에서 무너지지 않음 |

보고용 (판정에 쓰지 않음): 샤프, 최악의 해, 최악의 월, 세금 합계, 매매 횟수, 상승장(QQQ 연 +20% 이상인 해) 기회비용.

## 6. 진행 단계

| 단계 | 내용 |
| --- | --- |
| **P6-1** | 데이터 확장(QQQ 1999~, 국채, QLD 합성·검증, 환율) + 포트폴리오 엔진(비중·재조정·이동평균 취득가·세금) + 사전 등록 + P0·P3·P4·P5 (1999~2021) |
| P6-2 | 위성 조합 P1·P2·R0·R1 (2016~2021) + R1 주변값 + 사전 등록 |
| P6-3 | 계좌 구조: ISA(국내 상장 나스닥 100 ETF) vs 일반 해외 계좌, 월 납입 변형. 세법 수치는 실행 시점에 최신 규칙으로 확인 |
| P6-4 | 최종 후보 1개 고정 → 검증 구간(2022년~) 1회 개봉 → 판정 |

그 뒤: 실제 운용 규칙 확정 → 일일 보고서의 자금 계획 줄을 새 구조(코어·위성·대기·적립)로 바꾸기 → P4 자동화.

## 7. 부록 — 공포·탐욕 지수 연구 (2026-09-26 추가, P6-2와 함께 진행)

사용자 아이디어: "공포·탐욕 지수 25 이하에서 사고 75 이상에서 판다", "그 조건과 우리 신호가 겹칠 때 매수".

### 데이터 문제와 해결

- CNN 공포·탐욕 지수는 공개 과거 자료가 2011년부터 있으나 **2021-02 이전 값은 정확하지 않다**(자료 관리자 명시). 우리 학습 구간(2015~2021)은 대부분 이 부정확한 기간이고, 2022년~은 봉인되어 있다.
- 그래서 **무료 자료로 재현 가능한 대리 지수(FG-proxy)** 를 만든다: ① S&P 500의 125일 이동평균 대비 거리, ② VIX의 50일 이동평균 대비 거리, ③ 하이일드 스프레드(또는 HYG−IEF 20일 수익 차), ④ 안전자산 수요(주식−국채 20일 수익 차), ⑤ 가능하면 나스닥 100 종목의 52주 신고가−신저가 비율. 각 요소를 과거 1년 백분위로 바꿔 평균한 0~100 값.
- 검증: 대리 지수와 CNN 실제 값의 상관을 **2021-02 ~ 2021-12**(정확한 CNN 자료 + 학습 구간 안)에서 확인. 상관 0.7 미만이면 연구 중단.
- 대리 지수는 1999년부터 계산 가능 → 종목 없는 조합에는 1999~2021 전체 사용.

| 번호 | 내용 | 구간 |

| S1a | 1차 매수(A형)는 신호일 또는 최근 10거래일 안에 FG-proxy ≤ 25였을 때만 | 2016~2021 (위성) |
| S1b | FG-proxy ≤ 25일 때 A형 신호의 우선순위 가점 (걸러내지 않음) | 2016~2021 (위성) |

### 미리 적어 두는 예상 (결과 보기 전)

- S3(탐욕에서 팔기)는 공개 백테스트들에서 **상승장 수익을 놓쳐 보유 전략보다 나빴다**. 우리 결과도 비슷하면 채택하지 않는다.
- S1a는 P5-2에서 "QQQ 200일선 아래 신호가 더 좋았다"(기대값 2.09R vs 0.34R)는 결과와 방향이 같아 가능성이 있다. 다만 신호 수가 크게 줄어 표본이 작아진다.
- S2는 공포 구간 매수가 장기 보유와 결합될 때 좋았다는 공개 결과와 방향이 같다.

## 8. 그동안의 운영

- 신호 전략은 **모의 모드**로 계속 돌려 앞으로의 기록을 표본 외 검증 자료로 쌓는다.
- 실제 돈은 코어 QQQM 중심. 신호 매매를 계속한다면 소액(총자금의 10~20%)으로만.
