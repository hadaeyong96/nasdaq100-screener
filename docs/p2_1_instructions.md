# P2.1 보완 지시문 — P2 검토 결과 반영

---

P2 완료 보고를 검토했어. 판단 1, 3, 5, 6, 7은 그대로 채택이야. 아래 5가지를 보완해줘. 텔레그램·스케줄·드라이브는 여전히 만들지 마.

## 1. 매매 금지·한도 초과 신호는 상태를 바꾸지 않는다 (최우선)

지금은 금지된 신호도 상태 전이가 일어나고, 되돌려 보기에서 가상 체결까지 되는 것 같아. 그 결과 보유 종목이 정찰 7 + 확인 2 + 추세보유 5 + 청산중 11 = 25개로, 동시 보유 한도 8개를 크게 넘었어. 아래처럼 바꿔줘.

- 진입 신호(A1, A2, A3, B)가 매매 금지 구간에 걸리면 **상태 전이 없음**, 가상 체결 없음. `blocked` 이벤트로 사유와 함께 기록만 한다.
  - A2가 막힌 경우: 정찰 상태를 유지하고, A1 유효기간(10거래일) 안에 다음 골든크로스가 오면 다시 판정한다.
  - A3가 막힌 경우(갭, 구름 안 등): 확인 상태를 유지하고 다음 날 다시 판정한다.
  - B가 막힌 경우: 대기 유지.
- 동시 보유 8개, 종목당 투입 25% 한도를 **상태 전이 단계에서** 적용한다. 한도에 걸린 신규 진입(A1, B)은 점수 순으로 잘라내고, 잘린 신호는 `blocked: limit`으로 기록한다. 보유 중인 종목의 A2·A3 추가 매수는 종목 수 한도에서 제외(이미 보유 중이므로)하되 25% 투입 한도는 적용한다.
- 되돌려 보기에서도 같은 규칙을 쓴다 (같은 core 함수).
- 테스트 추가: 금지된 A2 → 정찰 유지 후 유효기간 내 다음 골든크로스로 A2 성공 / 9번째 신규 A1 → blocked / 금지된 신호는 가상 체결 없음.

## 2. A2의 RSI 조건은 "A2 당일" 기준으로

- 정리본 문구 "RSI 30 이상 70 미만 유지"는 **A2 판정 당일 RSI가 30 이상 70 미만**으로 해석한다. A1 이후 중간에 RSI가 다시 30 아래로 내려간 날이 있어도 A1은 무효로 하지 않는다 (손절 규칙이 관리).
- 현재 구현이 이와 다르면 고치고, 정리본과 코드 주석에 이 해석을 한 줄 남겨줘.

## 3. 같은 입력이면 같은 결과 (재현성 확인)

보고 8번에서 "연속 실행 사이에 경계선 신호가 흔들렸다"고 했는데, meta 값의 기준 시각이 9월 22일 16:00 ET로 같다면 값이 바뀌면 안 돼.

- 실행마다 종목별 (close, close_source, meta.regularMarketTime)을 `runs` 기록에 남겨줘.
- 캐시를 지우지 않고 `--dry-run`을 연속 2번 실행해 결과가 완전히 같은지, 캐시를 지우고 2번 실행해 같은지 확인해줘.
- 다르다면 어떤 종목의 어떤 값이 바뀌었는지 표로 보여주고 원인을 밝혀줘. `regularMarketTime`이 그 봉의 정규장 마감 시각과 다르면(장전·장후 가격일 가능성) 보완에 쓰지 않도록 조건을 좁혀줘.

## 4. 검토용 이벤트 이력 출력

`scripts/show_history.py TICKER` 스크립트를 만들어, 되돌려 보기 기간 동안 그 종목의 이벤트(신호, blocked, 체결 가정, 상태 변화, 손절가 변화)를 날짜순 표로 출력하게 해줘. 그리고 아래 세 종목 결과를 보고에 붙여줘.

- NVDA (오늘 추세 재진입 신호)
- ROP (오늘 E3가 묶음 9 전체로 나옴 — B형 보유 중 E1·E2가 먼저 나왔어야 하지 않았는지 확인)
- PEP (오늘 1차 신호)

## 5. 출력 정리

- 매수 신호 표에서 NVDA 행이 지정가·손절가·추천수량 없이 잘려 있었어. 모든 칸이 채워지는지 확인하고, 값이 없으면 그 이유(예: 한도 초과)를 적어줘.
- 매수 표에 `실적 발표일` 열을 추가해줘.

## 6. 완료 조건

- `pytest` 전부 통과
- 재현성 확인 결과 (연속 실행 결과 동일)
- `python -m engine.daily --replay`를 state.db를 지우고 다시 실행

## 7. 완료 보고 형식

```
[P2.1 완료 보고]
테스트: 통과 N / 실패 N
재현성: 캐시 유지 2회 동일 여부 / 캐시 삭제 2회 동일 여부 / 흔들림 원인
기준일: YYYY-MM-DD
단계별 종목 수: 대기 N / 정찰 N / 확인 N / 확정 N / 추세보유 N / 청산중 N (보유 종목 수 N ≤ 8 확인)
오늘 신규 매수 신호: (표, 실적 발표일 포함)
오늘 blocked 신호: (표, 사유)
오늘 매도·손절 신호: (표)
NVDA / ROP / PEP 이벤트 이력: (표 3개)
수정·추가 파일 목록: ...
판단이 필요한 부분: (없으면 "없음")
```

마지막으로 "P2.1 blocked signals and limits" 메시지로 커밋해줘. 푸시는 하지 마.
