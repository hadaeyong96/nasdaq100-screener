# 신기술 레이더 G0 — 규칙 고정 (결과 보기 전)

> 고정 2026-10-18, 브랜치 `research/tech-radar`. 이 문서와 코드(`core/radar/`, `data/radar/`)를 커밋한 뒤에 등록 결과를 계산한다.
> G0는 **데이터 관문**이다 — 수익 계산 없음, 판정 예산 사용 없음. 레이더 코드는 가격·수익 캐시를 열 수 없다(`data/radar/guard.py` 감사 훅 + 테스트).

## 1. 수집 (arXiv)

- 공식 OAI-PMH, `metadataPrefix=arXiv`. `export.arxiv.org/oai2`는 지금 `oaipmh.arxiv.org/oai`로 301 이동하므로 이동한 주소를 직접 부른다.
- OAI는 datestamp(메타데이터 수정일)로만 고를 수 있어 **전체를 받고** v1 제출일(`<created>`) ≤ 2021-12-31만 남긴다. 말뭉치는 v1 1991-01-01 ~ 2021-12-31(1991 전 v1 날짜 레코드는 뺀다 — 가장 이른 것 1988-11-11, 결과 계산 전 추가 2026-10-18). `<updated>`(수정 버전 날짜)는 쓰지 않는다.
- 요청 간격 3초 이상, 실패하면 30·60·120·300·600초 기다려 재시도, resumption token을 `state.json`에 저장해 이어받기.
- 저장(로컬 캐시만, git 제외): id, v1 제출일, 분야, 제목, 요약. 공개 저장소에는 원문을 커밋하지 않는다.
- 실행 기록 `runs.jsonl`: run_id, 수집 시각, 코드 버전(git 해시), 건수.
- 재현성: v1 달 하나(2015-03)를 근사 세기 없이 처음부터 다시 세어 표와 같은지 확인.

## 2. 달별 단어 표

- 글 = 제목 + 요약, 소문자. `$…$` 수식·`\명령` 제거. 구두점에서 끊고, 영숫자 아닌 글자(하이픈 포함)로 단어를 나눈다. 한 글자·숫자만인 단어는 끊는 자리.
- 표현 = 이어진 **2~3단어**. 첫 단어나 끝 단어가 불용어면 버린다(가운데는 허용 — "internet of things"). 불용어 목록은 `core/radar/term_monthly.STOPWORDS`.
- [사용자 결정 2026-10-18] **끝 단어 복수형을 단수로 합친다**(networks→network, batteries→battery; -ss·-us·-is·-ics·-ous와 예외 목록은 그대로).
- 논문 하나에 여러 번 나와도 1편. 전체 기간 언급 논문 합 **20 미만은 버림**(1차 근사 세기로 거르고 2차에서 정확히 셈).
- **학술 상투어**: 전체 달의 50% 넘는 달에서 비율 1% 넘는 표현 → 제외 목록(`boilerplate.csv`).
- 비율 = 그달 언급 논문 수 ÷ 그달 전체 논문 수. 출력 `term_monthly`(표현, 달, 언급 수, 전체 수, 비율, run_id).

## 3. 급증 등록

- 달 m: 최근 12개월(m−11 ~ m) **월별 비율 평균** ≥ 직전 36개월(m−47 ~ m−12) 월별 비율 평균 × 5, 그리고 최근 12개월 언급 논문 합 ≥ 50 → 등록.
- 직전 36개월이 다 있어야 판정(자료 첫 달 뒤 48번째 달부터). 직전 평균이 0이면 첫 조건 참. 처음 만족한 달 = 등록 달. 상투어는 등록하지 않는다.
- 출력: 연도별 등록 수, 연도별 상위 30개(전체 언급 수 순, 검토용).

## 4. 감지율 점검 (평가 전용 — 신호에 쓰지 않음)

- 20개 목록(지시문)을 같은 정규화로 찾아 등록 여부·등록 달·처음 등장 달·시차를 표로.
- [사용자 결정 2026-10-18] blockchain·bitcoin·graphene·lidar는 한 단어라 **구조상 등록 불가**로 센다. 같은 급증 규칙을 이 4단어에만 적용한 결과를 **참고 칸**에 따로 적는다(평가 전용).
- 등록 단어 무작위 50개(시드 20261018) → `docs/research/radar_terms_sample50.csv`(분류 칸 비움, 사용자 수동 확인).

## 5. 10-K·10-Q 회사 연결

- 등록 달이 2001-01 ~ 2021-12인 단어. EDGAR 전문 검색(efts), 기존 SEC User-Agent, 초당 10회 이하. 검색어 = `"단수" OR "복수"`, 10-K·10-Q, 접수일 2001-01-01 ~ 2021-12-31.
  EDGAR가 넘겨 주는 최대 1만 건에서 잘리는 단어는 따로 센다.
- 티커 = 그 공시 접수일에 그 CIK가 쓰던 티커. 구간 출처: S&P 500 소속 기간(fja05680, 1996~) × 확인된 티커↔CIK 표(S&P 500 신원표·나스닥100 ∪ S&P 100·S&P 400/600),
  나스닥100 ∪ S&P 100(2011~2021), S&P 400/600(2011~2021). 구간 밖·표에 없는 CIK = 매칭 실패(따로 집계).
- [사용자 결정 2026-10-18] 검색 결과 메타는 전부 저장. 문서(언급 수·앞뒤 200자 발췌)는 **티커 매칭된 공시 중 단어 × 접수 연도마다 최대 5건**(시드 20261018).
- 출력 `ticker_term_evidence`(티커, 단어, 접수일, 종류, 언급 수, 발췌, 검수 상태 = 미검수). 무작위 50건 → `docs/research/radar_link_sample50.csv`(분류 칸: 개발자/공급자/고객/경쟁/피해/무관).
