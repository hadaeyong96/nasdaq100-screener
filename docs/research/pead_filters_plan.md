# 실적급등 보완 필터 탐색 — 계획 (결과 계산 전)

> 작성 2026-11-12 · 브랜치 `research/pead-filters` · 이 문서를 커밋한 뒤 태그 `pead-filters-plan`을 단다.
> **탐색이지 판정이 아니다.** 원래 장부(`pead-watch-prereg`, configs/pead_watch.yaml·docs/prereg/pead_watch.md)는 바꾸지 않는다.
> 결과를 본 뒤 이 문서를 고치지 않는다. 고친 점이 생기면 결과 문서 「결과를 본 뒤 바꾼 점」에 적는다.

## 1. 목적

실적급등 신호(SW1 규칙)에 보완 필터 6개를 **각각 따로** 붙였을 때, 매매당 평균 초과와 고르는 힘(무작위 대비 백분위)이
필터 없는 기준보다 좋아지는지 본다.

## 2. 데이터·매매 (실적급등 타이밍 탐색과 같음)

- 신호: SW1 그대로 — 나스닥100 ∪ S&P100(그 전 달 말 명단), 반응일 +5%·QQQ 대비 +5%p·거래량 2배.
  `scripts/sw1_experiments.rebuild_announcements` 재현 636건(반응일 2012~2021) = `data/cache/sw1/announcements.csv` 신호와 같아야 한다.
- 매매: `core/pead_timing.make_trades` B1(반응일 다음 거래일 시가 매수) · 보유 90거래일(주) / 60거래일(참고),
  실제 매도 = 예정 매도 위치 이하 마지막 종가. 같은 종목 보유 중 새 신호 무시.
- 가격·비용·세금: `core/sw1`(수수료 0.07%·환전 0.1% 편도, 매도 연도 장부 순이익 22%), `core/pead_timing.price_trades`.
- 초과 = 신호 종목 − 같은 날 같은 가격 종류로 사고판 QQQ, 원화 비용·세금 뒤.
- **선택에 쓰는 구간은 반응일 2012~2021만.**
- 기준 = 필터 없음 B1·90 (알려진 값 549건 +0.67%, 2012~16 +1.08% / 2017~21 +0.23%), 참고 B1·60 (601건 +0.53%).
  계산 시작 때 이 두 값이 재현되지 않으면 멈춘다.

## 3. 필터 (각각 따로, 반응일 d0 장 마감까지 알 수 있는 정보만)

필터는 **신호에 먼저** 적용하고, 남은 신호로 매매를 만든다(걸러진 신호는 보유 중 겹침을 만들지 않는다).
각 필터의 신호는 세 갈래: 통과 / 걸러짐 / 판정 불가. 판정 불가는 통과로 치지 않는다(실제로 살 수 없음).

| 필터 | 통과 조건 | 판정 불가 |
| --- | --- | --- |
| F1 급등 지킴 | (d0 종가 − d0 저가) / (d0 고가 − d0 저가) ≥ 0.75 | d0 고가·저가 없음, 고가 = 저가 |
| F2 신고가 근처 | d0 종가 ≥ d0 **직전** 252개 종가(d0 제외, 그 종목 자기 행) 최고값 × 0.95 | 직전 종가 252개 미만 |
| F3 종목 추세 | d0 종가 > d0 포함 최근 200개 종가(그 종목 자기 행) 평균 | 종가 200개 미만 |
| F4 매출 가속 | 이번 분기 매출 전년 동기 대비 증가율 > 직전 분기 매출 전년 동기 대비 증가율 | 아래 XBRL 규칙 |
| F5 이익률 확대 | 이번 분기 영업이익 전년 동기 대비 증가율 > 이번 분기 매출 전년 동기 대비 증가율 | 아래 XBRL 규칙, 전년 동기 영업이익 ≤ 0 |
| F6 시장 상승기 | d0 QQQ 종가 > d0 포함 최근 200개 QQQ 종가 평균 | (없음 — QQQ는 1999년부터) |

- F1 고가·저가: 백테스트 parquet(고가·저가 있음) 종목은 그 파일, 나머지는 yfinance(`auto_adjust=False`의 High·Low·Close) 또는
  Tiingo(무료 키, raw high·low·close)에서 **같은 출처의 그날 종가와 함께** 받는다. 비율이라 분할 조정 여부는 상관없다.
  같은 출처 안에서 저가 ≤ 종가 ≤ 고가가 아니면 판정 불가.
- F2·F3 종가: 신호·매매와 같은 분할 반영 종가(`sw1_experiments.load_ohlc`).

### F4·F5 XBRL 규칙

- 출처: EDGAR companyfacts(무료, `data/edgar.fetch_company_facts` 캐시). 단위 USD, us-gaap 태그만.
  - 매출 태그(우선순위): Revenues → RevenueFromContractWithCustomerExcludingAssessedTax → SalesRevenueNet →
    RevenueFromContractWithCustomerIncludingAssessedTax → SalesRevenueGoodsNet → SalesRevenueServicesNet.
    증가율 하나(이번 값, 전년 동기 값)는 **같은 태그 둘**로 계산하고, 두 값이 다 있는 첫 태그를 쓴다.
  - 영업이익 태그: OperatingIncomeLoss 하나.
- 분기 값: 기간 80~100일 사실. 없으면(대개 회계연도 4분기) 같은 끝날 연간(350~380일) − 같은 시작일(±5일) 9개월(260~285일)로 만든다.
- 분기 맞추기: 이번 분기 끝날 = 그 실적 발표의 report_date(같은 분기 10-Q/10-K 기간 끝, ±5일).
  전년 동기 = 끝날이 그보다 365일 ± 10일 전. 직전 분기 = 끝날이 그보다 80~105일 전.
- **알 수 있는 시점 = d0 16:00(동부)**. 8-K 첨부 보도자료 수치는 XBRL로 받을 수 없어(무료 기계 판독 불가) 쓰지 않는다. 대신:
  - 사실의 제출일(filed) < d0 → 알 수 있음.
  - 제출일 = d0 → 그 사실이 같은 분기 10-Q/10-K에서 나왔고 그 공시의 색인 페이지 Accepted(동부) < d0 16:00일 때만 알 수 있음.
    그 밖의 공시에서 d0에 나온 사실은 쓰지 않는다.
  - 제출일 > d0 → 쓰지 않는다.
  - 같은 기간 값이 여러 공시에 있으면 알 수 있는 것 중 가장 늦게 제출된 값.
- 판정 불가 사유를 따로 센다: 같은 분기 보고서가 d0 장 마감 뒤 제출 / XBRL 매출(또는 영업이익) 없음 / 비교 분기 값 없음 /
  (F5) 전년 동기 영업이익 ≤ 0 / 전년 동기 매출 ≤ 0.

## 4. 지표 (필터마다, 90일·60일 각각)

- 매매당 평균 초과(비용·세금 뒤), 중앙값, 승률, 비용 전 달러 평균 초과
- 무작위 1,000회 백분위: 같은 매수일·같은 예정 매도일, 매수일 전 달 말 명단(신호 종목 제외) 무작위 1종목, 시드 20261111
  (타이밍 탐색과 같은 시드 — 기준 칸이 그 결과와 같게 나와야 한다)
- 매매 수, 기준 대비 남는 비율(= 필터 매매 수 / 같은 보유 기간 기준 매매 수)
- 2012~2016 / 2017~2021 평균 초과(반응일 연도)
- 나스닥100만 / S&P100만 평균 초과(참고, 반응일 전 달 말 명단 표시 기준, 둘 다면 양쪽에)
- 걸러진 쪽 신호로 만든 매매의 평균 초과·매매 수(참고). 판정 불가 신호 매매의 평균 초과·매매 수(참고)
- F4·F5: 판정 불가 비율·사유, 판정 가능 신호만으로 만든 필터 없음 판(참고)

## 5. 고르는 규칙 (90일 기준, 2012~2021)

1. 단일 필터 통과: 2012~16 평균 초과 > 기준 2012~16 **그리고** 2017~21 평균 초과 > 기준 2017~21
   **그리고** 매매 수 ≥ 기준 매매 수 × 0.40.
2. 통과 필터가 2개 이상이면, 통과 필터 중 평균 초과 상위 2개(동점이면 필터 번호 작은 쪽)를 **둘 다 통과해야 남는(AND)** 겹친 판을
   딱 1회 계산한다. 겹친 판은 매매 수 ≥ 기준 × 0.25 **그리고** 1번의 두 구간 조건을 만족할 때만 후보.
   (해석: 지시문은 겹친 판에 25%만 적었으나, 단일 필터와 같은 두 구간 조건을 함께 적용한다.)
3. 최종 선택: 후보(통과 단일 필터 + 후보가 된 겹친 판) 중 평균 초과 큰 순으로 최대 2개. 동점이면 매매 수 많은 쪽.
4. 통과 없음 → **「필터 없음 유지」**.
- 무작위 백분위·60일·나스닥100/S&P100·걸러진 쪽은 선택에 쓰지 않는다(표시만).

## 6. 2022 ~ 2026-09 (봉인 ⓐ, 이미 개봉) — 참고만

- 선택에 쓰지 않는다. **기준(B1·90)과 최종 선택만** 같은 방법으로 계산해 표시한다(봉인 ⓐ 데이터 `scripts/sealed_a_sw1*`,
  매도 예정일 2026-09-30 이내). 기준 B1·90은 알려진 값(336건 −0.69%)이 재현되지 않으면 멈춘다.
- 「필터 없음 유지」면 기준만 표시한다.

## 7. 순서

1. 이 계획 커밋 → 태그 `pead-filters-plan`.
2. 코드(core/pead_filters.py 순수 함수, data/pead_filters_data.py 수집·캐시, 테스트·미래 데이터 방지 테스트) 커밋 — 계산 전.
3. 데이터 받기(고가·저가, companyfacts, 같은 분기 10-Q/10-K Accepted). 받는 단계는 판정 불가 개수만 출력하고 수익은 계산하지 않는다.
4. 계산 1회 → `docs/research/pead_filters_results.md`. 스크립트는 시작할 때 이 문서가 태그와 같은지 확인한다.
5. 유료 데이터가 필요하면 멈추고 보고한다(결제 안 함). `research/pead-filters`에 커밋·push, main 병합 안 함.

## 8. 미리 알려진 약점

- 6개 필터 + 겹친 판을 한 번에 보므로 고른 판의 숫자는 위로 치우친다.
- 기준 B1·90 자체가 타이밍 탐색에서 백분위 동점(100.0)으로 골라졌고, 2022~ 참고에서 −0.69%였다.
- F4·F5는 보도자료 수치 대신 10-Q/10-K XBRL을 쓰므로, 분기 보고서를 반응일 뒤에 낸 신호는 판정 불가가 된다
  (데이터 조사 기준 신호의 약 60%가 10-Q/10-K를 반응일 뒤에 제출). 40% 조건을 못 넘을 가능성이 높다.
