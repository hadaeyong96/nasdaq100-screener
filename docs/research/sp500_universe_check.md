# S&P 500 시점별 구성 종목 무료 확보 가능성 점검

- 목적: R1(매출 성장)·PG1(PEG)을 아직 쓰지 않은 종목군 — **S&P 500 중 나스닥 100이 아닌 종목, 2012~2021** — 으로 검증할 수 있는지 판단
- 범위: 조사만. 백테스트·수익률 계산 없음
- 실행: `scripts/sp500_universe_check.py` (2026-10-08). 원자료와 표본 결과는 `data/cache/sp500/`(git 제외)에 있음
- 나스닥 100 시점별 구성은 E1과 같은 방식(`data/universe_history.point_in_time_universe` + `data/universe_fallback.csv`)

## 결론: **부분 가능**

| 매월 구성 명단 (2011-12~2021-12) | **가능** | 무료 출처 2개가 이름 변경을 빼면 일치. 빠지는 기간 없음 |

## 2) 2011-12~2021-12 매월 명단 재구성

- **A**: 이 구간에 857행, 매달 말 명단을 바로 꺼낼 수 있음. 가장 긴 행 간격은 88일(2020-06-22 → 2020-09-18)인데, B의 변경 표에도 이 사이 변경이 없다. 변경이 없어서 비어 있는 것이지 빠진 것이 아니다.
- **B**: 이 구간 변경 227행(편입 222, 편출 217). 날짜를 못 읽은 행 0.
- **빠지는 기간: 없음.**
- **A와 B 비교 (매달 말 121개월)**: 종목 수 A 497~506, B 505~510. 한쪽에만 있는 종목은 매달 14~47개다.
  - 대부분은 **이름 변경**이다. A는 그 시점 티커(FB, ABC, ANTM, BLL, WLTW, CBS, SYMC…)를 쓰고, B는 현재 티커(META, COR, ELV, BALL, WTW, PARA, GEN…)를 거꾸로 적용하기 때문이다.
  - 2021-12에 한쪽에만 있는 14개는 모두 이름 변경 짝이다 (FB↔META, ABC↔COR, FLT↔CPAY, PEAK↔DOC 등).
  - 차이가 가장 큰 곳은 2011-12~2012-04(A 497, B 508)다. 이름 변경에 더해 파산 꼬리 표기(ANRZQ·BTUUQ) 같은 표기 차이가 섞여 있다. 실제 구성 차이가 몇 개인지는 이름 변경 대조표 없이는 **확인 못 함**.
- 쓸 출처: **A를 주 출처로**(시점 티커라 EDGAR·가격 매칭에 유리), B는 대조용.

## 5) 예상 생존 편향 크기

- 가격을 못 받는 비율: 표본 **15/30 = 50%**, 이름 변경을 복구해도 **약 40%(12/30)**. 표본이 30개라 오차가 크다 (대략 ±18%p).
- E1(나스닥 100)에서 가격을 못 받은 26%보다 크다. 그런데 E1 결과 문서도 이미 "생존 편향이 성장주 고르기에 유리하게 작용할 수 있다"고 적었다.
- 편향 방향: 빠지는 종목은 인수(대개 웃돈을 받고 끝남)와 파산·급락(MNK 등)이 섞여 있다. 어느 쪽인지 정할 근거가 이 조사에는 없다 → **방향 확인 못 함, 크기는 "후보 종목의 절반 가까이를 관찰할 수 없다" 수준**.
- 사라진 종목이 성장 조건을 통과했는지 R1·PG1 판정으로 따지는 것은 결과 계산이라 하지 않았다.

## 쓰려면 필요한 일 (참고, 이번 범위 밖)

1. 이름 → CIK 매핑표: A의 시점 티커 + B의 회사 이름 → SEC CIK. 약 290개 수작업·반자동
2. 이름 변경 대조표: 옛 티커 → 현재 티커 (FB→META 등)
3. 가격: 상장폐지 종목의 무료 자동 출처가 없음 → **유료 데이터를 쓰거나, 가격이 있는 종목만 쓰고 결과에 "생존 편향 TRUE"로 표시**하는 것 중에서 정해야 함

- **파산은 구분 못 한다**. 파산 종목(ANRZQ·BTUUQ·MNK 등)은 위키에 "시가총액" 사유이거나 기록이 없다. 파산을 따로 세려면 다른 출처(SEC 8-K Item 1.03 등)가 필요하다 — 생존 편향의 방향(인수는 웃돈, 파산은 손실)을 정하려면 이 구분이 필요하다
- 사유 분류는 키워드 기반이라 사람이 한 번 훑어봐야 한다
