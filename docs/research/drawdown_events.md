## 해석·분석 선택 (사전 등록 원문에 없음 — 참고 표 전용, 사용자 확인 필요)

- 「그날」 = 사건의 −15% 도달일. 그날까지 공개된 값만 쓴다.
- 시작 20거래일 −10%: 고점 다음 20거래일 안에 고점 대비 −10% 이하 종가가 있었는지. (참고로 「도중 20거래일 −10%」 = 고점~바닥 사이 어느 20거래일 수익률이든 −10% 이하였는지, CSV에만)
- 샴: FRED SAHMREALTIME 현재 판(2019-09 이후 발표본과 과거 값 동일 확인). 월 m 값 공개일 = 월 m 말일 뒤 첫 UNRATE 발표일(ALFRED) — 근사.
- BAA10Y 백분위: 1986-01-02부터 그날까지 일별 값 중 그날 값 이하 비율. 표본 252일 미만이면 UNKNOWN.
- CAPE 백분위: 실러 현재 파일(빈티지 없음 → 사후 수정 반영됨), 월 m 값은 m+2월 1일부터 공개로 가정. 1881-01부터 분포, 표본 120개월 미만 UNKNOWN.
- 잠정 유형: 침체 = 샴 ≥ 0.5 또는 BAA10Y 백분위 ≥ 90 / 거품 = CAPE 백분위 ≥ 90 / 긴축 = DTB3 12개월 상승 ≥ 1.0%p(이 1.0은 분석 가정) / 깃발 2개 이상 혼합 / 깃발 없음 + 입력 모두 있음 + 빠른 하락이면 충격 / 그 밖 UNKNOWN.

## 읽을 때 주의

- ^KS11 사건에도 미국 지표(샴·BAA10Y·실러 CAPE·DTB3)를 그대로 붙였다(해외 판정에 미국 샴을 쓰는 사전 등록 H③과 같은 방식). 한국 경기·밸류에이션이 아니다.
- 실러 CAPE의 1881년부터 누적 백분위는 1999~2021년 달의 72.1%에서 90 이상이다(1950~1998 21.8%, 1972~1998 16.7%). 그래서 1996년 이후 사건 대부분이 「거품」 깃발을 받는다. 사전 등록 B2(CAPE 상위 10% 미만일 때만 진입)는 QQQ 구간에서 진입을 대부분 막을 수 있다.
- BAA10Y 백분위 ≥ 90인 날은 1999~2021 거래일의 27.4%.
- QQQ 2000-01-03 사건(−15.5%, 3거래일)은 야후 QQQ 2000-01-06 종가 이상치 때문일 가능성이 크다(같은 날 ^NDX는 고점 대비 −11.9%). 야후 QQQ 종가를 ^NDX 비율과 비교하면 2% 넘게 어긋난 날이 10일(1999-11-22, 2000-01-06·07, 2000-08-08, 2000-09-21, 2000-11-29, 2000-12-07·08, 2002-06-18, 2008-09-29).
