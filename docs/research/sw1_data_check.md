### 2-4. 발표 시각 (장 마감 후 발표인지)

| 방법 | 결과 |
| --- | --- |
| submissions JSON `acceptanceDateTime` | **쓸 수 없음**. 'Z'(UTC)가 붙어 있지만 공시마다 진짜 UTC이기도 하고 동부→UTC 변환이 두 번 들어간 값이기도 하다(AAPL은 모두 후자). 두 번 변환으로 가정하고 되돌린 값이 색인 페이지와 맞은 것: 무작위 12건 중 6건, 전체 2,313/6,622 (35%) |
| 공시 색인 페이지 `…-index.htm`의 Accepted | **쓸 수 있음**. 동부시간 벽시계 값. AAPL 8-K 16:30:23 = Apple 실적 발표 시각(동부 16:30)과 같음. 6,622건 모두 받음, 실패 0. 건마다 요청 1회(동시 6개, 초당 8회 이하) |

발표 시각: 장전(09:30 전) 3,252 · 장중 253 · 장후(16:00 이후) 3,117. 반응일: 장전은 그날, 장중·장후는 다음 거래일(결정 1).
