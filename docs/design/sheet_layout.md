## 0. 탭 순서

| 순서 | 탭 | 입력 | 역할 |
|---|---|---|---|
| 1 | 투자현황 | B2·B3 (노란 칸) | A·B 두 열: 자산, 코어·위성, 세금(근사), 업종별 비중 |
| 2 | 보유현황 | 없음 (전부 수식) | 종목별 현황 표(체결 B열 고유 티커마다 한 줄) |
| 3 | 매매일지 | 없음 (전부 수식) | 차수 묶음 하나 = 한 줄. 매수 → 현재 상태 → 매도 → 결과 |
| 4 | 체결 | **유일한 입력** | 사고판 기록. 프로그램(`data/sheets.py`)이 읽는 곳 |
| 5 | 계획 | 계획금액·기준가 | 구조 그대로. 1행 고정, B열 `#,##0`, D열(기준가) `0.00`(read_sheets가 보이는 값을 읽으므로 178.41이 178로 읽히지 않게). 자동 기록 v2가 첫 매수 후 줄을 추가 |
| 6 | 관심 | A열 티커 | GOOGLEFINANCE 가격·등락률 |
| 7 | 목록 (숨김) | 없음 | 티커·종목명·업종. 스크립트가 매번 새로 씀 |

## 1. 체결 탭

| 열 | 머리글 | 입력 | 검사(잘못된 값 거부) | 색 |
|---|---|---|---|---|
| A | 날짜 | 필수 | 유효한 날짜, `yyyy-mm-dd` | 연노랑 |
| B | 티커 | 필수 | `목록!A2:A` 드롭다운 | 연노랑 |
| C | 구분 | 필수 | 매수 / 매도 | 연노랑 |
| D | 수량 | 필수 | 0보다 큰 정수 | 연노랑 |
| E | 체결가($) | 필수 | 0보다 큰 숫자, `$0.00` | 연노랑 |
| F | 차수 | 매수 선택(비우면 자동) / **매도 필수** | 1차·2차·3차·재진입·대기자금, 빈칸 허용. 매도인데 비면 빨간색 | 아주 연한 노랑 |
| G | 종목명 | 자동 | `G2 =ARRAYFORMULA(IF(B2:B="","",IFERROR(VLOOKUP(B2:B,목록!A:B,2,FALSE),"?")))`, 보호 | 회색 |
| H | 손절가($) | 매수 때 선택 | 숫자, 빈칸 허용, `$0.00` | 아주 연한 노랑 |
| I | 매도이유 | 매도 때 선택 | 데드크로스·RSI 50 이탈·구름 이탈·손절·1차 만료·기타 | 아주 연한 노랑 |
| J | 규칙대로 | 선택 | 예·아니오 | 아주 연한 노랑 |
| K | 메모 | 선택 | — | 아주 연한 노랑 |
| L | 환율(원/$) | 선택 | 숫자, `#,##0.00` | 회색 |
| M | 수수료($) | 선택 | 숫자 | 회색 |

- 머리글 메모: F1 "살 때는 비우면 매수 순서대로 자동. 팔 때는 필수. 손절로 여러 차수를 팔면 차수별로 한 줄씩. QQQM 코어는 대기자금" / H1 "살 때 보고서의 손절가" / J1 "추천·손절 규칙대로 했나" / L1·M1 "비워 두면 자동"
- 1행 고정, A~F 열 좁게.
- 프로그램은 머리글 이름(괄호·공백 무시)으로 읽고 모르는 열(종목명·손절가·매도이유·규칙대로)은 무시한다.
- B·C·D 위치는 그대로라 계획 탭 보유주 수식(`'체결'!B:B·C:C·D:D`)은 영향이 없다.
- 열 정리는 값을 읽어 다시 쓰지 않고 **열 이동·빈 열 삽입**으로만 한다(데이터 값·서식 보존).

## 2. 매매일지 탭

- 1~2행 요약: 거래 수, 완료 수, 승률(실현손익 > 0 비율), 평균 R, 실현손익 합계(원), 규칙대로 "예" 비율
- 4행 머리글, 5행부터 `SORT(FILTER(보조 열))`로 펼침 — 체결 매수 줄(차수 "대기자금" 제외)마다 한 줄, 매수일 순
- 체결 2~401행(400줄 — 매수 200줄 + 매도 여유)을 따라간다. W열 이후는 숨김 보조 열(환율, 줄 키, 순보유, 차수 배정, 짝 매도 줄 등)

| 열 | 내용 |
|---|---|
| 종목명·티커·업종 | 목록 탭에서 |
| 차수 | 체결 F. 비었으면 프로그램(`data/fills.py _assign_units`)과 같게 종목별 매수 순서 1차→2차→3차(넷째부터 3차), 전량 매도로 0주가 되면 다시 1차 |
| 매수이유 | 1차 RSI 30 탈출 / 2차 골든크로스 / 3차 구름 돌파 / 재진입 추세 재진입 |
| 매수일·매수가·수량 | 그 매수 줄 |
| 투자금액(원) | 매수가 × 수량 × 환율(매수 줄 L, 없으면 현재 환율) |
| 손절가·목표가 2R | 매수 줄 H. 목표가 = 매수가 + 2 × (매수가 − 손절가), 손절가 없으면 빈칸 |
| 상태 | 짝 매도 없음 "보유 중" / 매도 수량 < 매수 수량 "일부 매도 (남은 N주)" / 같거나 크면 "매도 완료" |
| 현재가 | 보유 중·일부 매도일 때 GOOGLEFINANCE |
| 수익률 | 보유 중: 현재가 기준 평가 / 매도 후: 매도가 기준 |
| 매도일·매도가·매도이유 | 짝 매도 줄: 같은 티커·같은 차수, 매수일 이후 첫 매도 줄 |
| 실현손익(원) | (매도가 − 매수가) × 매도 수량 × 환율 − (매수·매도 수수료, 빈칸 0) × 환율. 환율은 매도 줄 L, 없으면 현재 환율 — **근사값** |
| R 배수 | (매도가 − 매수가) ÷ (매수가 − 손절가), 손절가 없으면 빈칸 |
| 보유일수 | (매도일 또는 오늘) − 매수일 |
| 규칙대로 | 매도 줄 J, 없으면 매수 줄 J |

한계: 같은 종목에서 차수를 직접 적은 매수와 비운 매수가 섞이면(예: 2차를 먼저 적고 다음 매수를 비움) 프로그램은 "안 쓴 차수 중 첫째"를, 시트는 "주기 안 매수 순번"을 써서 다를 수 있다. 매도는 첫 매도 한 줄만 짝짓는다.

## 3. 투자현황 탭 (A·B 두 열만)

| 행 | A 항목 | B 값 | 형식 |
|---|---|---|---|
| 1 | 항목 | 값 | 굵게 |
| 2 | **총 투자금(원)** | 입력 — 비었을 때만 40,000,000. 노란 칸 | `#,##0` |
| 3 | **종목당 계획금액(원)** | 입력 — 비었을 때만 5,000,000. 노란 칸 | `#,##0` |
| 5 | [자산] | | 구역 머리줄(굵게·회색) |
| 6 | 환율(원/$) | `GOOGLEFINANCE("CURRENCY:USDKRW")` | `#,##0.00` |
| 7 | 투자 중 원금(원) | 보유현황 투자 원금 합 | `#,##0` |
| 8 | 평가금액(원) | 보유현황 평가금액 합 | `#,##0` |
| 9 | 남은 현금(원) | B2 − B7 | `#,##0` |
| 10 | 투자 비중 | B7 ÷ B2 | `0.0%` |
| 11 | 전체 손익률 | (B8 − B7) ÷ B2 | `0.0%` |
| 13 | [코어·위성] | | 구역 머리줄 |
| 14 | 코어(QQQM) 평가금액(원) | 보유현황 구분 "코어" 평가금액 합 | `#,##0` |
| 15 | 코어 비중 | B14 ÷ B8 | `0.0%` |
| 16 | 위성 평가금액(원) | B8 − B14 | `#,##0` |
| 17 | 위성 비중 | B16 ÷ B8 | `0.0%` |
| 19 | [세금 (근사값, 실제는 증권사 기준)] | | 구역 머리줄 |
| 20 | 올해 실현손익(원) | 매매일지 실현손익 중 매도일이 올해인 것의 합 | `#,##0` |
| 21 | 250만 원 공제 남은 금액(원) | MAX(0, 2,500,000 − B20) | `#,##0` |
| 22 | 예상 양도세(원) | MAX(0, B20 − 2,500,000) × 22% | `#,##0` |
| 24 | [업종별 비중 (위성 대비)] | | 구역 머리줄 |
| 25~ | 업종 | 비중 | `0.0%`, 30% 초과 빨간 글씨 |

- 25행부터는 `QUERY(보유현황, 구분 = '위성' 이고 보유주 > 0, 업종별 평가금액 합, 큰 순서)` 결과를 `LET`·`HSTACK`으로 "업종 | 비중(÷ B16)" 2열로 펼친다. 코어(QQQM, 업종 ETF)는 빠진다. 업종이 없는 위성 종목은 "(미분류)".
- 보조 계산은 숨김 열로 두지 않고 보유현황·매매일지를 참조한다. C열 이후는 비운다. A열은 넓게, B열은 오른쪽 정렬.
- A2·A3 이름은 프로그램(계획 자동 기록 v2, `data/sheets.read_portfolio`)이 읽는다 — A열 전체에서 괄호·공백을 뺀 "총투자금"·"종목당계획금액"을 찾아(첫 행) 같은 줄 B열 값을 쓴다. 다른 A열 항목은 이 두 이름과 겹치지 않는다.
- 예전(v3.1) 배치에서 바꿀 때: 탭은 지우지 않고, 4행 이하와 C열 이후의 값·서식·메모만 한 번 지운 뒤 새로 쓴다(B2·B3 보존). 예전 조건부 서식은 지운다. C열 이후에 값이 있을 때만 이 정리를 한다.
- 투자 원금 = Σ(매수 수량 × 체결가 × 환율) − Σ(매도 수량 × 체결가 × 환율), 환율 빈칸은 현재 환율. 시트의 "투자 중 원금"은 대기자금(QQQM)을 **포함**하고, 프로그램의 남은 현금 경고(v2 규칙 C)는 **제외**한다.

## 3-1. 보유현황 탭

| 열 | 내용 |
|---|---|
| A 종목 | 체결 B열 고유 티커(대문자, 정렬) — 최대 200개 |
| B 종목명 · C 업종 | 목록 탭에서. 업종이 없으면 "(미분류)" |
| D 구분 | 코어 = 체결 차수 "대기자금" 줄이 있거나 목록 업종이 ETF(QQQM) / 위성 = 나머지 |
| E 보유주 | 매수 수량 합 − 매도 수량 합 |
| F 평균단가($) | 전체 매수의 가중평균(근사) |
| G 현재가($) | GOOGLEFINANCE |
| H 손익률 | 현재가 ÷ 평균단가 − 1 |
| I 투자 원금(원) | 위 투자 원금 식 |
| J 평가금액(원) | 보유주 × 현재가 × 현재 환율 |
| K 비중 | 평가금액 ÷ 평가금액 합 |

- M열(숨김): 현재 환율 보조. 보유 0주는 회색 글씨. 1행 고정, 탭 전체 "경고만 표시" 보호.
- 형식: 달러 `$0.00`, 원화 `#,##0`, 비율 `0.0%`.

## 4. 관심 탭

A 티커(목록 드롭다운, 유일한 입력), B 종목명, C 현재가, D 오늘 등락률, E 52주 최고가 대비 %, F 1개월 수익률, G 3개월 수익률 (GOOGLEFINANCE, 2~51행).

## 5. 목록 탭 (숨김)

A 티커, B 한글 종목명(`data/name_kr.csv` 전체 — 공식 한글 표기가 애매한 종목은 영문), C 업종(`data/sectors.py` GICS 영문, QQQM은 "ETF", 없으면 빈칸). 나스닥100 현재 구성 종목(`data/universe.get_universe`) + QQQM + 체결 탭의 모든 티커, 티커 오름차순.

## 6. 보호 ("경고만 표시")

목록 탭 전체, 매매일지 탭 전체, 보유현황 탭 전체, 모든 탭 1행, 체결 G열, 투자현황 전체(B2·B3 제외), 계획 탭 수식 열(2행 이하에 수식이 있는 열). 보호 설명은 `sheet_setup: …`로 붙여 다시 실행할 때 건너뛴다.

## 7. 스크립트 동작

- `python scripts/sheet_setup.py [시트ID] [--apply]` — 시트ID 생략 시 `.env` GOOGLE_SHEETS_ID. 시트 ID는 끝 4자리만 출력.
- 보기 모드: 바꿀 내용만 출력, 쓰기 0번, 백업도 안 만듦.
- 적용: ① 모든 탭 값·수식을 `outputs/sheet_backup_<시각>.json`에 저장 → ② 적용 → ③ 다시 읽어 체결 데이터(머리글 이름 기준)·계획(A2 외) 비교 → ④ `data/sheets.read_sheets()`·`read_portfolio()` 점검 출력.
- 멱등: 값·수식은 지금 값과 같으면 안 씀, 열 이동은 목표 순서면 0번, 보호·조건부 서식은 같은 것이 있으면 건너뜀, 검사·색·형식은 요청 해시를 시트 개발자 메타데이터(`sheet_setup_format_hash`)에 남겨 같으면 건너뜀.
- 탭 삭제·데이터 줄 삭제 없음. 계획 A2는 "OLED"일 때만 "ODFL"로.
- 스프레드시트 시간대는 Asia/Seoul로 유지(TODAY() — 보유일수·올해 실현손익이 한국 날짜 기준).
- 매매일지 보조 열(W열~)은 시트에서 실제 숨김 여부를 매번 확인해, 펼쳐져 있으면 다시 숨긴다.
