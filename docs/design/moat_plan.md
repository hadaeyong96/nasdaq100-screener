# 해자(경쟁 우위) 분석 계획서 v1.1

> 나스닥100 스크리너 · 작성 2026-10-01 · v1.1 갱신 2026-10-01
> 방향: 차트 신호로 "언제 살까"를 찾던 연구에서, 공시 숫자로 "무엇을 오래 들고 갈까"를 찾는 연구로 무게중심을 옮긴다.
> 조건: 무료 데이터만 사용 (SEC EDGAR, yfinance, Tiingo 무료)
> 상태: **지표 정의와 과거 검증 규칙 확정 → 잠금 대상** (5장의 잠금 이후 변경은 새 시도로 기록)

---

## 1. 왜 해자인가

| 지금까지 알게 된 것 | 해자 연구가 답하는 방식 |
|---|---|
| 차트 신호로 종목을 고르면 무작위와 차이가 없었다 | 가격이 아니라 **사업의 숫자**를 본다. 성격이 다른 정보다 |
| 잦은 매매는 양도세 22% 때문에 QQQM을 못 이긴다 | 해자 종목은 **오래 보유**하는 전략이라 매매가 적고 세금에 유리하다 |
| 무료 데이터로는 과거 가격 검증이 불완전하다 | 해자 판단 자료(공시)는 **SEC EDGAR에서 무료**로, 공시 제출일 기준으로 구할 수 있다 |
| 목표는 스스로 판단하는 실력을 기르는 것 | 해자 분석은 사람이 배우고 가르칠 수 있는 판단 기술이다 |

**역할 분담**
- 해자 분석 = **무엇을** 살까 (종목 선정, 연 1회 교체)
- 기존 MACD·RSI 신호 = **언제** 살까 (해자 종목의 매수 시점 보조)
- QQQM 코어 = 기본 자산

## 2. 해자의 5가지 원천

| 원천 | 뜻 | 나스닥100 예시 유형 |
|---|---|---|
| 무형자산 | 브랜드, 특허, 규제 허가 | 소비자 브랜드, 제약·바이오 |
| 전환 비용 | 고객이 다른 제품으로 바꾸기 어렵고 비쌈 | 기업용 소프트웨어, 반도체 설계 도구 |
| 네트워크 효과 | 사용자가 늘수록 가치가 커짐 | 플랫폼, 결제, 거래소 |
| 원가 우위 | 경쟁자보다 싸게 만들 수 있음 | 대형 유통, 물류 |
| 효율적 규모 | 시장이 작아 새 경쟁자가 들어올 이유가 없음 | 특수 장비, 틈새 인프라 |

원천은 사람이 판단한다(분석 카드). 프로그램은 **해자가 숫자로 나타나는지**를 확인한다.

## 3. 해자 지표 (v1.1 확정)

| 번호 | 지표 | 계산 | 해자의 흔적 | "좋음" 기준 [가정] |
|---|---|---|---|---|
| M1 | 영업 투하자본수익률 | 세후 영업이익(세율 21%) ÷ 영업 투하자본 | 사업에 묶인 자본으로 얼마나 버는가 | 최근 5년 중 4년 이상 15% 이상 |
| M2 | 매출총이익률 안정성 | 최근 5년 매출총이익률의 표준편차 (수준은 보지 않음) | 가격 결정력이 흔들리지 않는가 | 표준편차 3%p 이하 |
| M3 | 불황 버팀력 | 5년 중 가장 나빴던 해의 영업이익률 − 5년 평균 | 어려운 해에도 버티는가 | 하락폭 5%p 이내 |
| M4 | 이익의 현금화 | 영업현금흐름 ÷ 순이익 (최근 5년) | 이익이 진짜 현금인가 | 0.9 이상 |
| M5 | 희석 | 희석 주식 수 1년 변화율 | 성장 비용을 주주가 내는가 | 연 3% 미만 증가 |

**M1 영업 투하자본 (그린블랫 방식)**
- 영업 순운전자본 = (유동자산 − 현금·현금성자산 − 단기투자) − (유동부채 − 단기차입금)
- 영업 투하자본 = max(영업 순운전자본, 0) + 순유형자산
- 분모가 매출의 2% 미만인 해: 세후 영업이익이 플러스면 "기준 충족(자본 거의 불필요)", 값은 "100% 이상"으로 표시. 마이너스면 "측정 불가"
- 참고 열: 기존 식(자기자본 + 차입금 − 현금)

**데이터 처리 규칙**
- 공시 제출일(filed) 기준: 판단 시점까지 제출된 값만 사용
- XBRL 태그는 연도별로 우선순위대로 병합
- 매출 태그 불일치: 같은 연도 두 값이 5~50% 차이 → 큰 값 사용. 50% 넘게 차이 → 앞뒤 연도와 이어지는 값 사용, "검토 필요" 표시
- 영업이익 줄이 없으면 세전이익 + 이자비용, 이자비용도 없으면 세전이익 (표시 남김)
- 같은 회사의 여러 주식(GOOGL·GOOG)은 한 번만 셈

**해자 등급**
- 넓음: M1·M2·M4 모두 "좋음", M3·M5 중 "주의" 없음
- 좁음: M1·M2·M4 중 2개 "좋음"
- 없음: 그 외
- 판단 불가: 핵심 항목(매출·영업이익·자기자본) 연간 데이터 5년 미만

**해자 약화 경보** (보유 종목, 분기마다)
- 매출총이익률 2분기 연속 하락 **그리고** 전년 대비 2%p 이상 하락
- M1이 기준(15%) 아래로 떨어짐
- 핵심 질문 10번(내가 틀렸다는 신호)과 연결해 텔레그램 알림

### 3.1 v1 → v1.1 변경 기록 (모두 과거 검증 전에 결정)

| 변경 | 이유 | 결과를 보고 정했나 |
|---|---|---|
| M1 분모: 자기자본+차입금−현금 → 영업 투하자본 | 자사주 매입·현금 규모에 흔들려 MAR 6,583% 같은 무의미한 값 발생 | 계산 오류 수정 |
| M1: 운전자본 하한 0, 자본 거의 불필요 처리 | 선수금 많은 구독 기업(ADSK)이 오히려 측정 불가로 빠지는 문제 | 계산 오류 수정 |
| M2: 수준 기준(40%) 삭제 | 원가 우위형 해자(COST 등)를 구조적으로 배제 | 정의 수정 |
| M4: (영업현금흐름−설비투자)÷순이익 ≥0.8 → 영업현금흐름÷순이익 ≥0.9 | 핵심 질문 5번("이익이 현금으로 들어오나")과 정의 일치. 자본 집약도는 M1이 이미 반영 | **예.** 변경 시 MSFT 등 4개 종목 등급 변화를 알고 결정함. 시도 로그에 기록 |
| 태그 병합, 영업이익 대체, 40-F, 분기 각주 제거 | 실제 데이터 추출 버그 | 버그 수정 |

## 4. 과거 검증 규칙 (H4, 사전 등록)

| 항목 | 규칙 |
|---|---|
| 교체일 | 매년 4월 첫 거래일 (12월 결산 10-K 제출이 끝난 뒤). 판단 기준일은 그 전날 |
| 유니버스 | 교체일 당일의 실제 나스닥100 구성종목 (시점별 명단) |
| 편입 | "넓음" 등급 전부 |
| 비중 | 동일 비중. 단, 한 업종 최대 30% [가정]. 초과분은 나머지 업종에 비례 배분 |
| 보유 | 1년. 중간에 지수에서 빠져도 다음 교체일까지 보유. 인수·상장폐지로 현금이 생기면 QQQM으로 |
| 체결 | 교체일 다음 날 시가 + 슬리피지 0.05% |
| 비용 | 수수료 0.07%, 환전 0.1%, 양도세(연 250만 원 공제 후 22%), 배당 원천세 15% |
| 기간 | 2015년 4월 ~ 2021년 12월. **정식 구간 2019~2021** (가격 확보율 98% 통과), 2015~2018은 참고 |
| 봉인 | 2022년 이후 데이터는 사용하지 않음 |

**비교 대상**
- 대조군 A: QQQM 매수 후 보유 (2020년 10월 이전은 QQQ로 대체)
- 무작위 포트폴리오 1,000회: 같은 교체일, 같은 유니버스, 같은 종목 수, 같은 업종 제한으로 무작위 선택
- 보고용: "좁음 이상" 포트폴리오, "없음" 포트폴리오 (등급이 높을수록 성과가 좋은지 확인)

**판정 (탈락용)**
- 정식 구간에서 세후 수익률이 QQQM보다 낮으면 → **탈락**
- 무작위 포트폴리오 대비 백분위가 50 미만이면 → **탈락**
- 둘 다 통과하면 → **"탈락 아님"**. 합격이 아니며, 실시간 paper 검증으로 넘어간다
- 참고 구간(2015~2018)과 등급별 비교는 보고만 하고 판정에 쓰지 않는다

**합격 (실시간 paper)**
- 매월 등급 갱신, 연 1회 교체 규칙 그대로 paper 운영
- 24개월 세후로 QQQM을 이기고 무작위 대비 상위 25% [가정] → 합격

**미리 알아 둘 한계**
- 수익성·퀄리티 요인의 초과수익은 연구상 크지 않다.
- 나스닥100은 원래 우량 기업이 많아서, 넓음 포트폴리오(약 35개)와 QQQM의 차이가 작을 수 있다.
- 업종 분류는 yfinance(무료)의 현재 분류를 쓴다. 과거 시점 분류와 조금 다를 수 있다.
- 기대하는 효과는 "크게 이기기"보다 **"해자가 무너지는 종목을 피하고, 적게 매매하면서 세후로 조금 앞서기"**다.
