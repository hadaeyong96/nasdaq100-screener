# 이번 주 QQQ보다 강한 종목·업종 (작업 5-1, 관찰 목록)

브리핑 보고서의 **매수·매도 추천 바로 아래** 접기 하나(기본 닫힘): 「▶ 이번 주 QQQ보다 강한 종목·업종」.
관찰 표시 전용이다 — 신호·필터·상태·수량 계산은 읽지도 바꾸지도 않는다. 텔레그램 첨부 설명(caption)과
단체방 공개 보고서에는 넣지 않는다.

문구(접기 맨 위): "관찰용 · 매수 신호 아님 (1주 강세는 과거 시험에서 다음 상승을 예측하지 못함)"

## 규칙 (사전 등록, 2026-10-15 사용자 지시 — 임의 변경 금지)

- 대상: 그날 스크리너 명단(나스닥 100) 종목. QQQ는 기존 가격 수집(`data.prices.fetch_one`, 분할 반영 종가).
- 5거래일 수익률 = 기준일 종가 ÷ **QQQ 거래일 기준** 5거래일 전 종가 − 1. 두 날짜 중 하나라도 종가가 없으면 그 종목은 제외(표 아래에 제외 목록).
- 초과(%p) = 종목 5거래일 수익률 − QQQ 5거래일 수익률.
- 표 1 「이번 주 QQQ보다 강한 종목」: 초과 상위 10. 열: 종목, 이름, 업종 묶음, 초과 %p, 5일 수익률.
- 표 2 「이번 주 강한 업종」: 업종 묶음별 초과의 단순 평균, 상위 3·하위 3(하위는 약한 순).
  명단에 있고 계산된 종목이 2개 미만인 묶음은 표시하지 않는다. 묶음이 6개보다 적으면 상위에 나온 묶음은 하위에 다시 쓰지 않는다.
- 업종 묶음은 `config.yaml` `weekly_rs.groups`(사용자 지정 목록 그대로). 묶음에 없는 종목은 업종 묶음 "-".

## 실패 처리

QQQ 가격을 못 받으면 조용히 넘기지 않는다 — 로그(`[daily] QQQ 가격을 받지 못해 …`)와 접기 안 문구로 남긴다.
기존 브리핑·보고서의 나머지는 그대로 나간다.

- `core/weekly_rs.py` — 순수 함수 `compute_weekly_rs` (미래 데이터 금지 테스트 포함)
- `engine/daily.py` `build_weekly_rs_view` — QQQ 받기 + 종목명

## 같은 접기 안 표 2개 추가 — 「QQQ 이기는 힘이 세지는 종목」 (작업 6-1, 사전 등록 2026-10-15)

`core/accel.py`(브리핑 관찰 표·가상 장부 「한 달 가속 따라하기」·구역 ③ 판정이 같은 함수를 쓴다). 위 5거래일 표 2개 계산은 그대로다.

- RS선 = 종목 종가 ÷ QQQ 종가. 최근 힘 = RS(t)/RS(t−20) − 1, 직전 힘 = RS(t−20)/RS(t−40) − 1, 점수 = 최근 힘 − 직전 힘 (날짜는 QQQ 거래일 기준)
- 대상: 60거래일 이상 가격(t−59일 종가 있음, t·t−20·t−40 종가 있음), 기준일 종가 5달러 이상
- 표 3 「QQQ 이기는 힘이 세지는 종목 상위 10」: 종목, 이름, 업종 묶음, 점수(%p), 최근 힘, 직전 힘
- 표 4 「힘이 세지는 업종」: 같은 12개 묶음별 점수 평균 상위 3·하위 3(하위는 약한 순, 계산된 종목 2개 미만 묶음 제외)
- 문구는 접기 맨 위 "관찰용 · 매수 신호 아님" 그대로. 텔레그램 첨부 설명·공개 보고서에는 넣지 않는다
