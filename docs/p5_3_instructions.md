# P5-3 지시문 — 새 기준선(슬롯 5) + 성과 기여 분해 + C·E 묶음 실험

---

P5-2 결과를 검토했어. 결론: 공정 비교(a)에서 B0는 QQQ보다 −1.28%p, 가장 나은 슬롯 5도 −0.22%p라 아직 합격선(+2%p)과 거리가 멀어. 그리고 B4(쉬는 돈을 국채·현금으로)에서 수익이 절반 이하로 떨어진 걸 보면, **B0 수익의 대부분이 신호 종목이 아니라 쉬는 돈 QQQM에서 나왔을 가능성**이 커. 이번 단계는 "신호 종목 자체가 QQQ보다 나은가"를 먼저 분리해서 확인하고, 그다음 종목 선택·청산 실험을 해. 검증 구간(2022~)은 계속 봉인.

## 0. 새 기준선

- **B0.5 = B0 + 슬롯 5** (P5-2 유일한 개선)를 이번 단계의 기준선으로 쓴다. B0 결과도 비교용으로 표에 남겨.

## 1. 점검 (먼저)

1. **2016년 점검**: B0 2016년 +48.5%(QQQ 원화 +9.8%)를 **신호 종목 / QQQM / 환율 / 배당**으로 나눠 보여줘. 신호 종목 기여는 종목별 상위 5개와 그 손익(원화)까지. 가격 데이터 이상(분할 미반영, 튀는 값)이 없는지 해당 종목의 2016년 일봉도 확인.
2. **상위 10개 제외 계산 방식**: 2016년 초과 수익이 +38.9%p인데 상위 10개 포지션을 빼도 CAGR이 1%p만 떨어진 건 앞뒤가 안 맞아 보여. 계산 방식을 설명하고, 가능하면 **해당 포지션을 아예 진입하지 않은 것으로 다시 시뮬레이션**한 값으로 바꿔줘.
3. **B1 SMA190 = SMA200 완전 동일**: 두 결과가 소수점까지 같아. 기간 파라미터가 실제로 적용됐는지 확인해줘 (190일 기준 국면 일수와 200일 기준 국면 일수를 비교).

## 2. 성과 기여 분해 (이번 단계 핵심)

B0.5 기준으로:

- **신호 종목 부분만의 시간가중수익률(TWR)**: 종목에 돈이 들어가 있던 날의 종목 부분 수익률만 이어 붙인 연평균. 같은 날들의 QQQ 수익률(같은 비중을 QQQ에 뒀다고 가정)과 비교해서 **"종목 선택 초과 수익" = 신호 종목 TWR − 같은 기간 QQQ TWR** 을 계산.
- 평균 종목 투자 비중(총자금 대비 %), 최대·최소 비중.
- 세전 수익 기여를 **QQQM 보유분 / 신호 종목 / 비용 / 세금**으로 원화 금액 분해.
- **진입 유형별**(A형 바닥 반전 / B형 재진입) 포지션 수·승률·기대값 R·총손익, 그리고 **청산 유형별**(손절 / E1 / E2 / E3 / 1차 만료) 건수·평균 R.
- 판정: 종목 선택 초과 수익이 0보다 확실히 크지 않으면 보고서에 "신호 종목의 초과 수익 미확인"이라고 명시.

## 3. 단일 변수 실험 (B0.5 대비 하나씩)

| 번호 | 실험 | 비교값 |
| --- | --- | --- |
| C1 | 상대 강도 우대 | 없음 / QQQ 대비 6개월 수익률 상위 50%만 신규 진입 / 12개월 |
| C2 | RSI 30 반복 교차 제외 | 없음 / 최근 15거래일 내 RSI 30 상향 교차 2회 이상이면 A1 제외 |
| C3 | 거래량 조건 | 없음 / 신호일 거래량 > 20일 평균 × 1.5 / OBV가 20일 전보다 높음 |
| E1 | ATR 추적 손절 | 없음(현재 E1~E3) / 진입 후 최고 종가 대비 2.5 · 3.0 · 3.5 × ATR(14) 이탈 시 전량 매도 (기존 손절가는 유지, 둘 중 먼저 걸리는 것) |
| E2 | 분할 익절 | 없음 / 평균단가 대비 +2R 도달 시 보유의 절반 매도, 나머지는 기존 규칙 |
| T1 | 진입 유형 분리 | A형만 / B형만 (B0.5는 둘 다) |

- 각 실험의 주변값도 함께 (C1은 6·12개월, E1은 2.5·3.0·3.5가 주변값 역할).
- 조합은 아직 하지 마.

## 4. 판정 기준 (P5-2에서 쓴 값을 공식화)

- 개선: 세후 (a)와 (b) 모두 B0.5보다 +0.5%p 이상 높고, MDD가 1%p 넘게 나빠지지 않음
- 악화: (a)·(b) 중 하나라도 −0.5%p 이하
- 차이 없음: 그 사이
- 불안정: 주변값 중 하나가 기준 값보다 세후 (a)가 3%p 이상 낮음

## 5. 보고 표

P5-2와 같은 형식(세전·세후 (a)·(b)·QQQ 대비·MDD·샤프·승률·손익비·기대값 R·포지션 수·월평균 진입·양도세·한도 초과 탈락). **세전 열은 모든 줄에서 "수수료 반영, 세금 제외"로 통일**하고 QQQ 줄도 같은 정의로 맞춰줘.
