# P5-5 지시문 — 과거 구간 확장(2007~2014)으로 B0.5 표본 외 검증 + 2019년 분해

---

P5-4 결과를 검토했어. 결론은 "최종 후보 없음"이고 그대로 받아들인다. K1·K2, C2, E1은 채택하지 않는다 (C2가 걸러낸 신호는 평균 +0.55R로 돈을 벌던 신호였고, E1은 발동 0~5건이라 잡음 수준). 기준선은 **B0.5(B0 + 슬롯 5)** 로 유지한다.

이번 단계의 핵심 아이디어: B0.5는 2015~2021년만 보고 설계했어. 그러니 **2007~2014년은 이 전략이 한 번도 본 적 없는 데이터**야. 과거로 기간을 늘리면 검증 구간(2022년~)을 쓰지 않고도 **표본 외 검증을 한 번 더** 할 수 있고, 우리 신호가 강했던 하락장(2008년)도 들어간다. **이번 단계에서는 어떤 파라미터도 바꾸거나 고르지 않는다.** 검증 구간(2022년~)은 계속 봉인.

## 0. 사전 등록 (결과를 보기 전에 먼저, 가장 중요)

- 아래 3장의 판정 기준과 평가 대상(B0.5 = 주 대상, K1 = 참고용)을 `configs/p5_5_preregistration.yaml`에 적고, **백테스트를 돌리기 전에 먼저 커밋**해 (메시지 "P5-5 preregistration"). 보고서에 이 커밋 해시를 적어.
- 이 파일은 결과를 본 뒤 수정 금지.
- B0.5 설정은 P5-3·P5-4에서 쓴 것과 **완전히 같게** (코드 커밋 해시와 설정값을 보고서에 명시).

## 1. 데이터 확장

1. **시점별 나스닥 100 구성 종목을 2007년 1월까지** 거슬러 복원해 (가능하면 2000년까지).
   - 방법 예: 위키피디아 "Nasdaq-100" 문서의 과거 판(연 1회 이상 스냅샷)과 구성 변경 목록을 대조. 다른 신뢰할 만한 공개 자료가 있으면 그것도 교차 확인.
   - **연도별**로 "구성 종목 수 / 시세를 받은 종목 수 / 못 받은 종목의 종목·일수 비율"을 표로 보고. 어떤 연도의 누락 비율이 **30%를 넘으면 그 연도는 신뢰도 낮음**으로 표시하고, 시작 연도를 그 다음 해로 미룬다 (2007년이 안 되면 가능한 가장 이른 해).
   - `SURVIVORSHIP_BIAS = PARTIAL` 표시와 누락 목록(`missing_tickers_2007.csv`) 저장.
2. **QQQ**: 2007년부터 배당 포함 데이터. 기존 QQQM 접합 로직과 충돌 없는지 확인.
3. **원/달러 환율**: yfinance `KRW=X`가 부족한 기간은 FRED `DEXKOUS`(일간)로 보완하고, 두 자료가 겹치는 기간의 차이를 보고.
4. **세금 규칙**: 과거 실제 세법이 아니라 **지금 규칙(250만 원 공제 후 22%)을 전 기간에 똑같이** 적용한다고 보고서에 명시.
5. 실적 발표일 자료가 없는 기간은 실적 필터 미적용으로 표시 (P5-1과 같은 방식).

## 2. 평가 (파라미터 변경·선택 없음)

| 구간 | 성격 |
| --- | --- |
| **2007~2014** | 표본 외 (이번 판정의 주 대상) |
| 2015~2021 | 학습 구간 (P5-3 값과 같게 나오는지 재현 확인용) |
| 2007~2021 | 전체 (통계 검정력 확인용) |

각 구간에서 **QQQ, B0.5, K1** 을 P5-3과 같은 표 형식으로 (세전·세후 (a)·(b)·QQQ 대비·MDD·샤프·승률·손익비·기대값 R·포지션 수·양도세).

추가로:
- **연도별 초과 수익 표** (2007~2021, (a) 기준)
- **국면별 성과**: QQQ 200일선 위/아래, 그리고 2008년 금융위기(2007-10 ~ 2009-03)와 그 회복기(2009-03 ~ 2010-12)를 따로
- **무작위 진입 비교** (500회, P5-4와 같은 방식·같은 시드 규칙): 2007~2014, 2007~2021 각각의 백분위
- **부트스트랩** (20일 블록, 2,000회): 2007~2021 연 초과 수익의 95% 구간 (참고용, 판정에는 안 씀)
- **성과 기여 분해** (P5-3 방식): 2007~2014 구간의 종목 선택 초과 수익(신호 종목 TWR − 같은 기간 QQQ TWR), QQQM·종목·비용·세금 원화 분해
- **2015~2021 재현 확인**: B0.5 결과가 P5-3 값과 다르면 원인(데이터 갱신, 구성 종목 변경 등)을 설명

## 3. 판정 기준 (사전 등록할 내용, B0.5에만 적용)

| 판정 | 조건 |
| --- | --- |
| **합격** | 2007~2014 세후 (a)가 QQQ보다 **+1%p 이상** · MDD가 QQQ 이하 · 2007~2014 무작위 진입 **95백분위 이상** — 세 가지 모두 |
| **보류** | 2007~2014 세후 (a)가 QQQ 대비 −1%p ~ +1%p, 또는 위 세 가지 중 두 가지만 충족 |
| **불합격** | 2007~2014 세후 (a)가 QQQ보다 −1%p 미만 |

- K1은 **참고용으로만 보고**하고, 이번 단계에서 채택 후보가 될 수 없다.
- 결과가 나빠도 그대로 보고. 판정을 바꾸려고 기준·기간·설정을 건드리지 말 것.

## 4. 2019년 분해 (2015~2021 구간, 판정과 무관한 원인 분석)

P5-4 Walk-Forward에서 2019년이 QQQ보다 −14.49%p였어. B0.5 기준으로:
- 2019년 수익을 **신호 종목 / QQQM / 환율 / 배당 / 비용 / 세금**으로 원화 분해
- 2019년 신호 종목 손익 상위·하위 5개
- 2019년 QQQM 매매 횟수와 그로 인한 양도세
- 평균 종목 투자 비중과, 비중이 QQQ 상승 구간에 어떻게 움직였는지
- 한 줄 결론: 차이의 주원인이 무엇인지

## 5. 실행 방식

- P5-4처럼 **체크포인트** 저장 (`outputs/backtest/p5_5_checkpoint/`), `python -u`와 `flush=True`로 진행 표시, 무작위 비교는 병렬 + 고정 시드.
- 독립 프로세스로 백그라운드 실행하고, 진행 확인 방법을 알려줘.
- 전략 로직(`engine/`)은 데이터 기간 확장에 꼭 필요한 부분 말고는 바꾸지 말 것. 바꾸면 무엇을 왜 바꿨는지 보고.
