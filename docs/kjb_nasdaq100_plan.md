# 김종봉 투자법 → 나스닥 100 적용안 (KJB-NQ)

> 근거: 구글 드라이브의 `kjbreportv1.md`(대본 23건 종합보고서), `KJB_V01.md`(개발 기준·사용설명서). 대본 원문 23개는 지운 프로젝트에만 있어 이번에는 **분석 문서 기준**으로 옮긴다.
> 목적: 김종봉 투자법의 핵심 규칙을 한국 시장 → 나스닥 100으로 옮겨, **우리 백테스트 엔진으로 돌려볼 수 있게** 숫자 규칙으로 정리한다.
> 원칙: 원자료 등급(CONFIRMED / INTERPRETED / HYPOTHESIS / UNKNOWN)을 그대로 쓰고, 한국 → 미국으로 옮기면서 생긴 변환은 모두 INTERPRETED 이하로 표시한다.

---

## 1. 왜 따로 시험할 가치가 있나

- 우리 전략(RSI 30 반등)은 **약한 종목의 반등**을 산다. 김종봉 투자법은 **시장을 처음 이기기 시작한 강한 종목**을 산다. 철학이 반대라 서로 다른 정보를 쓴다.
- 지금까지 검토 기록에 따로 쌓인 후보 **C1b(하락장 버팀 상대강도), C5(섹터 모멘텀), F1(거래량 동반 돌파)** 가 김종봉 투자법 안에 한 묶음으로 들어 있다. 하나씩 시험하지 않고 **한 번에 시험**하면 실험 수가 줄어 과적합 위험이 작아진다.
- 이 규칙들은 2016~2021년 데이터를 보고 만든 게 아니다. 따라서 **2016~2021년은 김종봉 규칙에게 사실상 처음 보는 데이터**다 (단, 파라미터를 고르지 않을 때만).

## 3. 백테스트 주 설정 (사전 등록 대상)

| 항목 | 값 |
| --- | --- |
| 유니버스 | 시점별 나스닥 100 구성 종목 (P5와 같음) |
| 기간 | **2016-01 ~ 2021-12** (무료 데이터 누락 30% 미만 구간). 2022년~은 봉인 |
| 신호 | 2장 #3 + #4 + #5가 **같은 날** 모두 충족 (첫 발생) |
| 우선순위 | ① 섹터 상대강도 높은 순 → ② "처음" 점수(직전 60일 초과일 수) 낮은 순 → ③ 거래대금 배율 높은 순. 거래대금 상위 10종목은 맨 뒤 |
| 매수 | 신호 다음 날 지정가 = 종가 × 1.01 (시가 ≤ 지정가면 시가, 저가 ≤ 지정가면 지정가 체결, 아니면 미체결) |
| 비중 | 위성 자금의 1/10씩, 최대 10종목, 섹터당 최대 3종목 |
| 손절 | 종가 < 신호일 저가 → 다음 날 시가 매도 |
| 청산 | 매수 후 63거래일 되는 날 다음 날 시가 매도 |
| 재진입 | 같은 종목은 청산 후 20거래일 동안 신규 신호 무시 |
| 쉬는 돈 (위성 안) | 단기 국채 (P6의 쿨다운 없는 방식) |
| 포트폴리오 | 코어 QQQM 70% (팔지 않음, 배당 재투자) + 위성 30% |
| 비용·세금 | P5·P6와 같음 (수수료 0.07%, 환전 0.1%, 250만 원 공제 후 22%, 이동평균 취득가) |

## 5. 함께 보고할 것

- 연도별 신호 수와 체결 수 (장대양봉 +5%가 대형주에서 얼마나 드문지)
- 섹터별 신호 분포, 섹터 확산도가 높을 때 vs 낮을 때 평균 R
- "처음" 점수 구간별(0~10 / 11~30 / 31~60일) 평균 R — 김종봉의 핵심 주장("처음"일수록 좋다) 직접 검증
- 우리 신호(A형 RSI 30 반등)와 같은 날 겹친 종목 수 (철학이 반대라 거의 없을 것으로 예상)
- 대장주 선행 신호(2장 #2)와 이후 20일 QQQ 수익률의 관계 (참고)

## 6. 한계

- 원자료는 한국 중소·중형주 중심. 나스닥 100 대형주에서는 +5% 장대양봉과 거래대금 급증이 드물어 신호가 적을 수 있다.
- 재무 필터(#15)와 지수 비중 조절(#16)을 빼고 시험한다. 원 투자법 전체가 아니라 **종목 선택 핵심부**만 시험하는 것이다.
- 섹터는 현재 분류라 과거와 다를 수 있다.
- 김종봉 투자법은 "발견 ≠ 매수, 최종 판단은 사람"이다. 이 백테스트는 사람의 판단 없이 규칙대로만 샀을 때의 결과다.
