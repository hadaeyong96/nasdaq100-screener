# P5 백테스트 계획서 v2 — 최종 (GPT·제미나이 검토 반영)

> 목적: 어떤 설계가 **세후로 QQQ를 이기는지**, 그리고 **왜 이기는지**를 숫자로 확인한다.
> 원칙: 최고값을 찾는 최적화가 아니라, 주변 값·다른 기간에서도 버티는 설계를 고른다.

## 1. 합격 기준

| 기준 | 내용 |
| --- | --- |
| 수익 | 세후 연평균 수익률이 **QQQ 보유(배당 재투자, 세후)보다 2%p 이상** 높음 |
| 위험 | 최대 낙폭(MDD)이 QQQ 이하 |
| 기간 | 학습 구간과 **2022년 이후 검증 구간 모두** 충족, Walk-Forward 각 구간에서 크게 무너지지 않음 |
| 거래 품질 | 거래당 기대값 0.2R 이상, 손익비 1.5 이상 |
| 보고용 (합격 기준 아님) | 승률, 샤프, Profit Factor, 월평균 신호 수 |

합격 조합이 없으면 → **"QQQM 보유 + 국면 필터로 하락 방어"** 를 대안으로 검토.

## 2. 데이터·실행·비용 모형

| 항목 | 내용 |
| --- | --- |
| 기간 | 2015-01 ~ 최신. 학습 2015~2021, 검증 2022~ (1회만) |
| 종목 | 시점별 구성 종목(가능 시). 불가 시 현재 구성 사용 + `SURVIVORSHIP_BIAS = TRUE` 표시 |
| 체결 모형 | 신호 다음 날 지정가 = 종가 × 1.01. **시가 ≤ 지정가 → 시가 체결**, 시가 > 지정가이지만 **저가 ≤ 지정가 → 지정가 체결**, 저가 > 지정가 → 미체결 |
| 손절 체결 | 장중 저가 ≤ 손절가 → 손절가 체결, 시가가 이미 아래면 시가 체결 (갭 하락 반영) |
| 실행 민감도 | 체결가를 시가 / 지정가 / 종가 기준으로 바꿔 결과가 얼마나 흔들리는지 비교 |
| 비용 | 수수료 매수·매도 각 0.07%, 환전 스프레드 0.1% (설정값) |
| 세금 | 해외주식 양도세: 연간 실현손익에서 250만 원 공제 후 22%. 배당 원천징수 15% 후 재투자 |
| 수익률 분리 | 세전 / 비용 차감 / 세후를 각각 보고 |
| 금지 | 미래 데이터 사용, 없는 데이터 임의 생성, 세금 빠진 결과를 세후로 표시 |

## 5. 분석과 검증

| 항목 | 내용 |
| --- | --- |
| 국면별 성과 | 상승·전환·약세 국면으로 나눠 수익률, MDD, 승률, 기대값, 거래 수 |
| 성과 기여 (단순) | QQQM 보유분 / 신호 종목 선택 / 현금·국채 / 비용·세금 |
| 주변값 검증 | 채택 후보의 바로 옆 값도 괜찮을 때만 채택 (예: 200일선 → 190·210일선) |
| Walk-Forward | Train 2015~2018 → Test 2019, 2016~2019 → 2020, 2017~2020 → 2021, 2018~2021 → 2022 (데이터 범위 확인 후 확정) |
| 검증 구간 | 최종 조합 1개를 2022~최신에서 **한 번만** 확인. 보고 나서 다시 조정하지 않음 |
| 탈락 기록 | 매수 못 한 신호와 탈락 이유(필터·한도·미체결)를 모두 기록해 "놓친 수익" 분석 |

## 6. 보고 지표

기본: 세후 CAGR, QQQ 대비 초과, MDD, 샤프, 승률, 손익비, 기대값(R), 거래 수, 월평균 신호
추가: MDD 지속 기간, 회복 기간, 평균 보유 기간, Profit Factor, 최악의 거래·월·연도, 세전·비용·세후 분리

결과 상태는 **PASS / FAIL / BLOCKED / UNKNOWN** 으로 구분하고, 나쁜 결과를 고쳐서 PASS로 만들지 않는다.
