# P3.8 지시문 — 일일 보고서 맨 위에 "시장 온도" (CNN 공포·탐욕 지수 + FRED 지표 5개)

---

일일 보고서 맨 위(자금 계획 줄 위)에 시장 전체 분위기를 보여 주는 **CNN 공포·탐욕 지수 + FRED 지표 5개**를 넣어줘. 공포·탐욕 지수가 VIX 자리를 대신한다. `docs/report_template.html`의 배치·문구·CSS를 그대로 따를 것. **표시 전용**이야. 신호·필터·수량 계산 등 어떤 매매 규칙에도 쓰지 않는다 (P5-2에서 국면 필터가 성과를 나쁘게 만들었음). P6 작업 파일(`engine/portfolio.py`, `scripts/p6_*`, `configs/p6_*`)은 건드리지 말고, 이번 작업만 따로 커밋해.

## 1. 지표와 자료

| 칸 | 지표 | FRED 코드 | 표시 상태 기준 (config에서 읽기) |
| --- | --- | --- | --- |
| 1 | **CNN 공포·탐욕 지수** (FRED 아님) | CNN 자료 (아래 참고) | 0~24 "■ 극단적 공포" · 25~44 "▲ 공포" · 45~55 "● 중립" · 56~75 "▲ 탐욕" · 76~100 "■ 극단적 탐욕". 선 그래프는 0~100 고정 축, 25·75 점선 |
| 2 | 미국 10년물 국채금리 | `DGS10` | 63거래일(약 3개월) 전 대비 +0.5%p 이상 오르면 주의, 그 외 안정 |
| 3 | 장단기 금리차 (10년−2년) | `T10Y2Y` | 0.5%p 이상 정상 · 0~0.5 주의 · 0 미만 경계(역전) |
| 4 | 하이일드 스프레드 | `BAMLH0A0HYM2` | 4% 미만 안정 · 4~6% 주의 · 6% 이상 경계 |
| 5 | 미국 기준금리 상단 | `DFEDTARU` | 3개월 전보다 높으면 "▲ 인상 흐름", 낮으면 "▼ 인하 흐름", 같으면 "● 동결" (정보 색) |
| 6 | 원/달러 환율 | `DEXKOUS` (최근 며칠은 기존 `KRW=X`로 보완) | 1년 중 상위 20%면 "▲ 달러 비쌈", 하위 20%면 "▼ 달러 쌈", 그 외 "● 보통" |

- 자료는 FRED 공개 CSV(`https://fred.stlouisfed.org/graph/fredgraph.csv?id=코드`)로 받는다. API 키가 필요하면 `.env`의 키 이름만 확인하고 **값은 절대 출력하지 말 것**. P5-5의 `data/fx.py` FRED 함수를 재사용할 수 있으면 재사용.
- 매일 최근 1년 이상 받아서 캐시(`data/cache/fred/`)에 저장. 못 받으면 캐시 값 + 칸에 "지연" 표시 + 경고 탭에 한 줄.
- FRED 지표는 발표가 하루~며칠 늦을 수 있다. 각 칸에 **그 지표의 실제 기준일**을 쓰고(머리줄 "기준일"은 가장 늦은 날짜), 보고서 기준일보다 5거래일 넘게 오래되면 "지연" 표시.
- **CNN 공포·탐욕 지수**: CNN은 공식 API가 없고, 웹 페이지가 쓰는 공개 자료 주소(`https://production.dataviz.cnn.io/index/fearandgreed/graphdata/시작일`)에서 JSON으로 받는다. 비공식이라 언제든 막히거나 형식이 바뀔 수 있으니, 요청은 **하루 1회**, 브라우저와 같은 User-Agent, 실패하면 캐시 값 + "지연" 표시, 3일 넘게 실패하면 이 칸을 **VIX(`VIXCLS`)로 대체**하고 경고 탭에 한 줄. 받은 값은 `data/cache/fear_greed.csv`에 날짜별로 계속 쌓는다 (나중에 연구용). CNN 이용 약관상 개인 참고용으로만 쓰고 보고서 외부 공개는 하지 않는다.
- 과거 자료(연구용, 보고서 표시에는 필요 없음): 공개 저장소 `whit3rabbit/fear-greed-data`에 2011년부터 있으나 **2021-02 이전 값은 여러 출처를 이어 붙인 것이라 정확하지 않다**고 저장소 스스로 밝히고 있다. 이번 단계에서는 받지 말 것.
- 하이일드 스프레드(ICE BofA 자료)는 FRED에서 제공 기간이 짧거나 막힐 수 있다. 1년치를 못 받으면 받은 만큼만 그리고 칸에 "기간 짧음" 표시.

## 2. 칸 구성 (템플릿 그대로)

- 이름 + FRED 코드 / 현재 값 + 단위 / **1주 전 대비 변화** / 1년 추이 작은 선 그래프(마지막 점 강조, 기준선이 있는 지표는 점선) / 상태 배지(● 안정 · ▲ 주의 · ■ 경계처럼 **기호 + 글자**, 색만으로 구분하지 않기) / 기준 설명 한 줄.
- 칸에 마우스를 올리면 "지표 이름 · 1년 최저 ~ 최고"가 보이게 (title).
- 머리줄: "시장 온도 · FRED 장기 지표 · 기준일 · 변화는 1주 전 대비 · **참고용이며 매매 규칙에는 쓰지 않습니다**" + "지표 읽는 법 →"(읽는 법 탭으로 이동).
- PC 6칸 한 줄, 좁은 화면 3칸, 휴대폰 2칸 (템플릿 CSS). 다크 모드에서도 확인.
- "읽는 법" 탭에 템플릿의 "시장 온도 지표 6가지" 표를 넣는다 (기준 숫자는 config 값으로 채우기).

## 3. 설정 (`config.yaml`)

```yaml
macro:
  enabled: true
  fear_greed: {source: cnn, fallback: VIXCLS, fallback_after_days: 3}
  series: [DGS10, T10Y2Y, BAMLH0A0HYM2, DFEDTARU, DEXKOUS]
  thresholds:  # 표시 전용
    FEAR_GREED: {extreme_fear: 25, fear: 45, neutral_high: 55, greed: 75}
    VIXCLS: {caution: 20, alert: 30}  # 대체용
    DGS10: {rise_3m_caution: 0.5}
    T10Y2Y: {normal: 0.5, alert: 0}
    BAMLH0A0HYM2: {caution: 4, alert: 6}
    DEXKOUS: {pct_high: 80, pct_low: 20}
  stale_days: 5
```

- 글 맨 위에 한 줄만 추가: `시장 온도: 공포·탐욕 58 탐욕 · 10년물 4.12% · 금리차 +0.48 · HY 3.05% · 기준금리 4.50% 인하 · 환율 1,380 달러 비쌈`. 주의·경계가 있으면 그 지표만 앞에 ⚠ 표시.

## 5. 테스트

- 상태 판정 경계값 (공포·탐욕 24/25/44/45/55/56/75/76, 대체 VIX 19.99/20/30, 금리차 0/0.5, HY 4/6, 환율 백분위 80/20, 기준금리 인상·인하·동결)
- FRED CSV의 빈 값(".") 처리, 휴일, 캐시 대체와 "지연" 표시
- 선 그래프 좌표 생성 (값이 모두 같을 때 0 나누기 없이)
- 이 지표가 신호·수량 계산에 쓰이지 않는지 (지표 값을 바꿔도 신규 매수 목록·수량이 같은지)
- `pytest` 전부 통과
