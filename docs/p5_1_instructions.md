# P5-1 지시문 — 백테스트 엔진 + 벤치마크 + 기준선(B0)

---

CLAUDE.md, docs/strategy_v3.md, **docs/p5_plan.md** 를 먼저 읽어줘. 이번 단계는 P5-1 범위만 한다. 실험(A~F 묶음)은 아직 돌리지 마.

## 0. 먼저 확인 (P3.7이 안 됐다면 먼저 처리)

- `.claude/settings.json`에 `.env` 읽기 금지(Read ./.env, 그리고 cat/type/Get-Content .env 같은 Bash 명령 차단)가 없으면 먼저 만들고 CLAUDE.md에 규칙을 추가해. `.env` 값은 절대 열거나 출력하지 마.
- paper 모드 가상 체결 수량이 보고서 수량(슬롯 + 위험 상한 + 남은 한도)과 같지 않으면 먼저 통일해.

## 1. 원칙

- **라이브와 같은 core 함수**를 쓴다 (`core/indicators`, `signals`, `filters`, `sizing`, `state`). 백테스트 전용 신호 코드를 새로 만들지 않는다.
- 미래 데이터 금지: t일 신호는 t일까지의 데이터로만, 체결은 t+1일.
- **검증 구간(2022-01-01 이후)은 봉인**한다. 이번 단계의 B0 결과는 2015~2021 학습 구간만 계산·보고한다. 벤치마크는 전체 기간을 계산해도 되지만 보고는 학습 구간 기준으로.

## 2. 데이터

- 기간: 2015-01-01부터 (지표 준비용으로 2014년 데이터 추가 수집 가능).
- 종목: 나스닥 100. **시점별 구성 종목**을 구할 수 있는지 조사해 (위키백과 구성 변경 이력 표 등). 구할 수 있으면 그 날의 구성 종목만 신호 대상으로 쓰고, 어렵다면 현재 구성 종목을 쓰고 결과에 `SURVIVORSHIP_BIAS = TRUE`를 표시해. 어떤 방식을 썼는지 보고해.
- 추가 시세: QQQ, QQQM(상장 전 기간은 QQQ로 대체하고 보수 차이를 반영), 원/달러(`KRW=X`), 배당 이력(QQQ·QQQM·종목).
- 누락 거래일 복구와 data_gap 규칙은 라이브와 동일하게.

## 3. 포트폴리오 시뮬레이션 (engine/backtest.py)

- 자금: 총자금 4,000만 원(원화 기준), 일별 환율로 달러 환산.
- **B0 설정**: 전략 v3, 슬롯 8개, 전략 한도 60%, 현금 버퍼 5%, 쉬는 돈 QQQM. 수량은 라이브 보고서와 같은 `core/sizing` (슬롯 + 위험 상한 + 남은 한도 + 2·3차 예약).
- 매수 자금은 QQQM을 팔아 마련하고, 매도 대금은 QQQM을 다시 산다 (현금 버퍼 유지).
- **체결 모형**:
  - 매수: 다음 날 지정가 = 신호일 종가 × 1.01. 시가 ≤ 지정가 → 시가 체결 / 시가 > 지정가이고 저가 ≤ 지정가 → 지정가 체결 / 저가 > 지정가 → 미체결(기록).
  - 손절: 사용자는 증권사 손절 예약을 쓰므로 **장중 기준**. 저가 ≤ 손절가 → 손절가 체결, 시가가 이미 손절가 아래면 시가 체결.
  - E1·E2·E3·1차 만료 매도: 신호 다음 날 시가.
- **비용**: 수수료 매수·매도 각 0.07%, 환전 스프레드 0.1% (config로 조정 가능).
- **세금**: 해외주식 양도세는 원화 기준 연간 실현손익(매도 원화금액 − 매수 원화금액 − 비용)에서 250만 원 공제 후 22%, 다음 해 5월에 납부한 것으로 처리. 배당은 15% 원천징수 후 재투자.
- **벤치마크 세후 계산**은 두 가지로: (a) 기간 끝에 전량 매도해 세금까지 낸 경우, (b) 팔지 않은 경우(미실현). QQQ 보유는 세금을 미룰 수 있다는 장점이 있으므로 둘 다 보여줘.

## 4. 기록

- `outputs/backtest/<run_id>/` 에 저장: `equity.csv`(일별 자산, QQQM·종목·현금 구분), `trades.csv`(진입·청산·차수·R·사유·세전/세후 손익), `rejected.csv`(체결 안 됨·필터·한도·data_gap 등 **매수 못 한 신호와 이유**), `summary.md`.
- `run_id`에는 날짜·설정 해시를 넣고, 사용한 config 전체를 함께 저장한다 (재현용).

## 5. 지표 (summary.md)

- 세전 / 비용 차감 / 세후 CAGR, QQQ 대비 초과(세후 a·b 둘 다)
- MDD, MDD 지속 기간, 회복 기간, 샤프, 승률, 손익비, 기대값(R), Profit Factor
- 거래 수, 월평균 신호 수, 평균 보유 기간, 최악의 거래·월·연도
- 데이터 상태: 유니버스 방식, `SURVIVORSHIP_BIAS`, data_gap 종목·일수, 미체결 비율
- 상태 표시: PASS / FAIL / BLOCKED / UNKNOWN (합격 기준은 p5_plan.md 1장)

## 6. 테스트

- 백테스트 미래 데이터 방지: t일까지 자른 데이터로 계산한 t일 신호 = 전체 데이터의 t일 신호
- **라이브·백테스트 일치**: 같은 날짜 구간에서 `engine.daily`와 백테스트가 같은 신호·같은 수량을 내는지 (최근 20거래일 샘플)
- 체결 모형 경계값 (시가 체결 / 지정가 체결 / 미체결, 손절 갭 하락)
- 세금 계산: 공제 250만 원, 손실 연도, 연도 넘김 납부
- 모두 네트워크 없이 (고정 샘플 데이터)
