# KJB-1 지시문 — 김종봉 투자법 핵심부를 나스닥 100에 적용한 백테스트

---

`docs/kjb_nasdaq100_plan.md`를 먼저 읽고 그대로 따를 것. 김종봉 투자법의 종목 선택 핵심("3개월 만에 처음 시장을 이긴 종목 + 거래대금 급증 + 장대양봉 + 강한 섹터")을 나스닥 100에 옮겨, 코어 QQQM 70% + 위성 30% 구조로 시험한다. 검증 구간(2022년~)은 봉인. 결과가 나빠도 그대로 보고해.

**선행 조건**: P6-1.1 수정(200일선 준비 기간, P0 동등성, 폭락 표)과 실전 9/24·9/25 처리가 끝난 뒤에 시작한다. 끝나지 않았으면 먼저 알려줘.

## 0. 사전 등록 (계산 전에 먼저)

- 계획서 3장(주 설정·주변값)과 4장(비교·판정·표본 부족 기준)을 `configs/kjb1_preregistration.yaml`에 옮겨 적고, **어떤 백테스트도 돌리기 전에** 커밋 ("KJB-1 preregistration"). 이후 수정 금지.

## 1. 신호 계산 (`core/kjb.py`, 신규 · 순수 함수)

- 63거래일 상대수익 = 종목 63일 수익률 − QQQ 63일 수익률 (둘 다 배당 반영 전 종가 기준으로 통일하고 보고서에 명시)
- "처음 초과": 오늘 > 0, 어제 ≤ 0, 직전 63거래일 동안 > 0인 날이 없음
- "처음" 점수: 직전 60거래일 중 일간 상대수익(종목 등락률 − QQQ 등락률) > 0인 날 수
- 거래대금 배율 = 당일 (종가 × 거래량) ÷ 직전 20일 평균
- 장대양봉: 종가 등락률 ≥ +5% 그리고 종가 > 시가 (주변값: 20일 일간 변동성 × 2.5)
- 섹터 상대강도·확산도: 시점별 구성 종목의 현재 GICS 섹터로 동일가중 계산
- 대장주 선행 신호: 그날 거래대금 상위 2종목의 20일 수익률 − QQQ 20일 수익률 (보고용)
- **미래 데이터 금지**: 모든 값은 신호일 종가까지의 자료만 사용. 테스트로 확인.

## 2. 시뮬레이션

- P5 백테스트 엔진의 체결·비용·세금 모형을 재사용하되, 진입·청산 규칙은 계획서 3장대로 새로 연결 (`engine/kjb_satellite.py` 또는 기존 엔진에 전략 인터페이스로 추가 — 기존 B0.5 결과가 바뀌지 않아야 함).
- 포트폴리오: P6 포트폴리오 엔진으로 코어 QQQM 70%(팔지 않음) + 위성 30%. 비교용으로 **B0.5를 같은 70/30 구조**에 넣은 것도 계산.
- 무작위 진입 500회 (같은 날짜·같은 건수·같은 청산 규칙, 종목만 그날 활성 구성 종목 중 무작위, 고정 시드, 병렬).
- 체크포인트(`outputs/backtest/kjb1_checkpoint/`), `python -u` + `flush=True`, 독립 프로세스 백그라운드 실행, 진행 확인 방법 안내. 시험 출력은 프로젝트 안(`outputs/tmp/`)에만.

## 3. 테스트

- 신호 함수 경계값 (상대수익 0 전후, 직전 63일 초과 이력 있으면 신호 없음, 배율 1.99/2.00, 등락률 4.99/5.00%, 음봉 제외)
- 미래 데이터 금지 (신호일 이후 자료를 바꿔도 신호가 같음)
- 섹터당 최대 3종목, 최대 10종목, 재진입 20일 금지
- 기존 B0.5 결과가 P5-3 값과 같게 재현 (회귀 방지)
- `pytest` 전부 통과
