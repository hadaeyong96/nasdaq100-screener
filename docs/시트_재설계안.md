## 1. 핵심 흐름과 우리 전략에 맞춘 단위

사용자 제안: `종목명 | 섹터 | 매수일 | 매수가 | 수량 | 투자금액 | 현재가 | 수익률 | 목표가 | 손절가 | 매도일 | 매도가 | 실현손익 | 매수이유 | 매도이유`

**한 줄 = 한 차수 묶음(1차·2차·3차·재진입)으로 한다.**
- 우리 전략은 차수마다 **사는 이유가 다르고**(1차 RSI 30 탈출, 2차 골든크로스, 3차 구름 돌파), **파는 이유도 묶음별로 다르다**(1차 묶음 = 데드크로스, 2차 묶음 = RSI 50 이탈, 3차 묶음 = 구름 이탈).
- 그래서 차수 묶음 하나가 "매수 → 매도"가 짝지어지는 자연스러운 거래 단위다. 매수이유·매도이유가 줄마다 하나로 깔끔하게 정해진다.
- 손절은 모든 묶음을 한 번에 판다 → 체결에 차수별로 한 줄씩 적는다.

## 2. 사용자 항목 → 우리 버전

| 사용자 항목 | 우리 버전 | 어디서 |
|---|---|---|
| 종목명 | 종목명 + 티커 | 자동 (목록 탭) |
| 섹터 | 업종 | 자동 (목록 탭) |
| — (추가) | **차수** | 체결 입력 |
| 매수이유 | **신호** (차수에서 자동: RSI 30 탈출 / 골든크로스 / 구름 돌파 / 추세 재진입) | 자동 |
| 매수일·매수가·수량 | 그대로 | 체결 매수 줄 |
| 투자금액 | 투자금액(원) = 수량 × 매수가 × 환율 | 자동 |
| 손절가 | 매수 때 보고서의 손절가를 적음 | 체결 매수 줄 (선택) |
| 목표가 | **2R 가격** = 매수가 + 2 × (매수가 − 손절가). v3 전략의 "2R 도달 알림"과 같은 기준 (v3에는 별도 목표가 없음) | 자동 |
| — (추가) | **상태**: 보유 중 / 매도 완료 | 자동 |
| 현재가·수익률 | 보유 중: 현재가와 평가 수익률 / 매도 후: 실현 수익률 | 자동 (GOOGLEFINANCE) |
| 매도일·매도가 | 같은 티커·같은 차수의 매도 줄 | 체결 매도 줄 |
| 매도이유 | 드롭다운: 데드크로스 / RSI 50 이탈 / 구름 이탈 / 손절 / 1차 만료 / 기타 | 체결 매도 줄 |
| 실현손익 | 원화, (매도가 − 매수가) × 수량 × 환율 − 수수료 | 자동 |
| — (추가) | **R 배수** = (매도가 − 매수가) ÷ (매수가 − 손절가) | 자동 (손절가 있을 때) |
| — (추가) | 보유일수, 규칙대로 | 자동 / 체결 입력 |

## 4. 체결 탭 (v3.1)

| 열 | 머리글 | 입력 | 검사 |
|---|---|---|---|
| A | 날짜 | 필수 | 유효한 날짜 |
| B | 티커 | 필수, 드롭다운 | 목록에 없으면 거부 |
| C | 구분 | 필수, 드롭다운 | 매수 / 매도 |
| D | 수량 | 필수 | 0보다 큰 정수 (매도도 양수) |
| E | 체결가($) | 필수 | 0보다 큰 숫자 |
| F | 차수 | 매수: 선택 (비우면 자동) / **매도: 필수** | 1차 / 2차 / 3차 / 재진입 / 대기자금. 매도인데 비면 빨간색 |
| G | 종목명 | 자동 | 회색, 보호 |
| H | 손절가($) | 매수 때 선택 | 숫자. 보고서 손절가를 그대로 |
| I | 매도이유 | 매도 때 선택, 드롭다운 | 데드크로스 / RSI 50 이탈 / 구름 이탈 / 손절 / 1차 만료 / 기타 |
| J | 규칙대로 | 선택, 드롭다운 | 예 / 아니오 |
| K | 메모 | 선택 | — |
| L | 환율(원/$) | 선택 (회색) | 비우면 자동 |
| M | 수수료($) | 선택 (회색) | 비우면 자동 |

- 프로그램은 머리글 이름으로 읽고 모르는 열(종목명·손절가·매도이유·규칙대로)은 무시 → 코드 변경 없음.
- B·C·D·E·F 위치는 그대로 (계획·투자현황 수식 영향 없음).
- 차수 "대기자금"(QQQM 코어) 줄은 매매일지에서 뺀다 (장기 보유라 거래 단위가 아님). 투자현황 코어 칸에서 따로 본다.

## 5. 매매일지 탭 (전부 수식)

| 열 | 내용 |
|---|---|
| 종목명 · 티커 · 업종 · 차수 · 매수이유 | 체결 매수 줄(대기자금 제외)마다 한 줄 |
| 매수일 · 매수가 · 수량 · 투자금액(원) | 그 매수 줄 |
| 손절가 · 목표가(2R) | 매수 줄 손절가, 2R 계산 |
| 상태 | 같은 티커·차수의 매수 뒤 매도 줄이 있으면 "매도 완료", 없으면 "보유 중" |
| 현재가 · 수익률 | 보유 중이면 현재가·평가 수익률, 완료면 매도가 기준 실현 수익률 |
| 매도일 · 매도가 · 매도이유 | 같은 티커·차수, 매수일 이후 첫 매도 줄 |
| 실현손익(원) · R 배수 · 보유일수 · 규칙대로 | 자동 |
| 맨 위 요약 | 거래 수, 완료 수, 승률, 평균 R, 실현손익 합계, 규칙대로 비율 |

- 일부만 판 경우(매도 수량 < 매수 수량)는 "일부 매도"로 표시하고 남은 수량을 보여 준다.

## 6. 투자현황 탭 (v3와 같음)
