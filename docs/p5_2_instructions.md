# P5-2 지시문 — 기준선 보완 + 첫 단일 변수 실험 (A1·B1·B2·B4)

---

P5-1.1 결과를 검토했어. 계산은 이제 믿을 만해. 이번 단계는 **0장 보완 → 1장 실험** 순서로 해줘. 검증 구간(2022~)은 계속 봉인. 결과가 나빠도 그대로 보고해.

## 0. 기준선 보완 (먼저)

1. **B0도 (a) 청산 시나리오 계산**: 기간 끝에 전량 매도하고 양도세까지 낸 B0 세후 CAGR을 따로 계산해줘. 지금은 B0 미청산 값을 QQQ (a)와 비교하고 있어서 공정하지 않아. 앞으로 모든 실험은 **(a)끼리, (b)끼리** 비교.
2. **세금 납부 환전**: 양도세를 원화로 낸다고 보고, 납부할 때 환전 스프레드 0.1%를 적용해줘.
3. **최대 손실 −5.88R 점검**: 손절 구조상 한 포지션 손실이 −1.5R을 크게 넘으면 안 돼. 이 포지션의 종목·날짜·진입·손절·청산 내역을 보여주고 원인을 밝혀줘 (갭 하락, 2·3차 매수 후 손절가 처리, R 기준 등). 버그면 고치고, 실제 갭이면 그대로 둬.
4. **연도별 초과 수익 집중도**: B0는 2016년에 +48.5%(QQQ 원화 +9.8%)로 이 한 해가 초과 수익 대부분을 만든 것 같아. 연도별 초과 수익(B0 − QQQ)과, **상위 10개 포지션을 빼면** CAGR이 얼마가 되는지 보여줘.

## 1. 단일 변수 실험 (B0 대비 하나씩)

| 번호 | 실험 | 비교값 |
| --- | --- | --- |
| A1 | 동시 보유 슬롯 | 8(B0) / 5 / 4 |
| B1 | QQQ 200일선 필터 | 없음(B0) / QQQ 종가 > 200일 단순이동평균일 때만 신규 매수(A1·B). 보유 종목 청산 규칙은 그대로 |
| B2 | QQQ 일목 구름 필터 | 없음(B0) / QQQ 종가 > 구름 상단 & 앞구름 양운일 때만 신규 매수 |
| B4 | 쉬는 돈 보관처 | QQQM(B0) / 단기 국채 ETF(SGOV, 상장 전은 BIL 또는 3개월 국채 수익률로 대체) / 현금(이자 0) |

- B4는 "QQQM 반복 매매로 생긴 양도세 약 798만 원"이 신호 전략의 성과를 얼마나 깎는지 확인하는 실험이야. 수량 계산(총자금 기준)은 B0와 같게.
- B1·B2의 주변값도 함께: 200일선은 190 / 200 / 210일.
- 각 실험은 **다른 조건은 전부 B0와 같게**.

추가로:
- **국면별 성과**: QQQ 200일선 위/아래 기간으로 나눠 B0의 수익률·승률·기대값

## 3. 판정 규칙

- 한 실험이 B0보다 나은지 판단할 때 **세후 (a)와 (b) 모두**, 그리고 **MDD**를 함께 본다.
- 주변값(190/210) 중 하나라도 크게 무너지면 "불안정"으로 표시하고 채택 후보에서 뺀다.
- 조합은 아직 하지 마. 이번엔 단일 변수 결과만.
