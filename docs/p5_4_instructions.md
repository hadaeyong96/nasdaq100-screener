# P5-4 지시문 — 후보 조합 + 견고성 검증 + 실력인지 운인지 확인

---

P5-3 결과를 검토했어. C2(RSI 30 반복 교차 제외)가 처음으로 합격선(세후 (a) QQQ +2%p)을 넘었고, E1 ATR ×3.5도 개선이었어. 하지만 **상위 10개 포지션을 빼면 CAGR이 20.38% → 14.63%로 무너질 만큼** 소수 종목(특히 2016 NVDA) 의존도가 커. 그래서 이번 단계는 "좋아 보이는 값을 고르는 것"보다 **그 결과가 주변값·다른 기간·무작위 비교에서도 버티는지**를 확인하는 게 목적이야. 검증 구간(2022~)은 이번에도 **봉인**. 결과가 나빠도 그대로 보고해.

## 0. 보완

1. **ATR 추적 손절 청산 사유 분리**: `STOP`과 섞이지 않게 `ATR_TRAIL`로 기록.
2. **E2 분할 익절 체결 통일**: 다른 청산과 같게 "다음 날 시가 체결"로 바꿔. (E2 재판정은 필요 없음, 코드 일관성용)

## 1. C2 견고성 (주변값)

C2 = "최근 N거래일 안에 RSI 30 상향 교차가 K회 이상이면 A1 제외". B0.5 기준으로:

| N (거래일) | K=2 | K=3 |
| --- | --- | --- |
| 10 | | |
| 15 (P5-3 값) | ✔ | |
| 20 | | |

- 6개 칸 모두 세후 (a)·(b)·MDD·포지션 수 보고.
- **C2(15일·2회)에서 상위 10개 포지션을 막은 반사실 시뮬레이션**도 해줘. B0.5보다 소수 종목 의존도가 줄었는지, 늘었는지.
- C2로 **제외된 A1 신호들의 성과**(만약 들어갔다면의 R 분포)를 따로 집계해줘. 정말 나쁜 신호를 걸렀는지 확인용.

## 2. E1 추적 손절 배수 확장

- ×3.5 / 4.0 / 4.5 / 5.0 (B0.5 기준, 단일 변수).
- **최고값을 고르지 말 것**. 선택 규칙: 세후 (a)가 **양옆 값과 모두 1%p 이내**인 구간(평탄 구간) 중 가장 작은 배수를 고른다. 평탄 구간이 없으면 E1은 "불안정"으로 채택하지 않는다.
- `ATR_TRAIL` 발동 건수와 평균 R을 함께 보고.

## 3. 조합 (최대 2개)

| 이름 | 구성 |
| --- | --- |
| K1 | B0.5 + C2(15일·2회) |
| K2 | B0.5 + C2(15일·2회) + E1(2장에서 규칙으로 고른 배수, 불안정이면 K2 생략) |

## 4. 실력인지 운인지 (K1, K2 각각)

1. **무작위 진입 비교 (몬테카를로 500회)**: 같은 기간·같은 월별 진입 건수·같은 수량 규칙·같은 청산 규칙으로, 종목만 **그날의 나스닥 100 활성 종목 중 무작위**로 골라 500번 시뮬레이션. 우리 전략의 세후 (a) CAGR이 500개 분포에서 **몇 번째 백분위**인지 보고. (95백분위 이상이면 "무작위보다 확실히 나음", 50~95면 "애매", 50 미만이면 "무작위 수준 이하")
2. **부트스트랩 신뢰구간**: 일별 초과 수익(전략 − QQQ)을 20일 블록 단위로 재표본 2,000회 → 연 초과 수익의 95% 신뢰구간. 구간이 0을 포함하는지 명시.
3. **연도별 초과 수익 표**: 2015~2021 각 연도 (전략 − QQQ). 초과 수익이 난 연도 수 / 7.

## 5. Walk-Forward (검증 구간 제외)

- C2의 (N, K)와 E1 배수를 **학습 창에서만** 1·2장의 작은 격자 안에서 골라(같은 선택 규칙), 바로 다음 1년에 적용:
  - Train 2015~2017 → Test 2018
  - Train 2015~2018 → Test 2019
  - Train 2015~2019 → Test 2020
  - Train 2015~2020 → Test 2021
- 각 Test 연도의 세후 수익률 vs QQQ, 그리고 매 창에서 선택된 파라미터가 **흔들리는지** 보고.
- 2022년 이후는 쓰지 않는다.

## 6. 최종 후보 고정

- 위 결과로 최종 후보 1개(K1 또는 K2, 둘 다 약하면 "없음")를 골라 설정을 `configs/p5_final_candidate.yaml`로 **고정 저장**해줘 (파라미터·데이터 기준일·코드 커밋 해시 포함). 다음 단계(P5-5)에서 이 파일 그대로 검증 구간을 **한 번만** 열 거야. 이 파일은 이후 수정 금지.

## 7. 완료 보고

```
[P5-4 완료 보고]
테스트: 통과 N / 실패 N
1장 C2 견고성 표 (6칸) / C2 상위 10개 제외 반사실 / C2가 걸러낸 신호의 R 분포
2장 E1 배수 표 / 평탄 구간 판정 / 선택 배수 / ATR_TRAIL 발동 건수·평균 R
3장 조합 결과 표 (P5-3 형식, B0.5·K1·K2)
4장 무작위 진입 백분위 / 부트스트랩 95% 구간 / 연도별 초과 수익 표
5장 Walk-Forward 표 (Test 연도별 결과, 선택된 파라미터)
6장 최종 후보와 고정 파일 경로 (또는 "후보 없음"과 이유)
상태: PASS / FAIL / BLOCKED / UNKNOWN
수정 파일 목록
판단이 필요한 부분
```

"P5-4 robustness, luck test, walk-forward" 메시지로 커밋해줘. 푸시는 하지 마.
