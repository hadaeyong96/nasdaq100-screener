# 실적급등 추천 장부 — 기록 꼬리표 정의 (2026-11-12, 코드 전)

- 원 사전 등록(`docs/prereg/pead_watch.md`, `configs/pead_watch.yaml`, 태그 `pead-watch-prereg`)은 고치지 않는다. 이 문서는 **기록 항목만** 더한다.
- 꼬리표는 **판정·매매에 쓰지 않는다.** 신호 조건·매수·매도·비용·세금·판정 규칙은 그대로다. 나중에 꼬리표로 신호를 나눠 보는 일은 새 사전 등록이 있어야 하고, 이 장부의 판정을 바꾸지 않는다.
- 이 문서를 코드보다 먼저 커밋한다. 구현 중 다르게 해석한 부분이 생기면 이 문서는 고치지 않고 `docs/prereg/pead_watch_impl.md` 끝에 따로 적는다.

## 1. 언제·어디에

- 새 신호(판정 결과 `signal = 1`)마다 한 번, 판정과 같은 실행에서 계산해 `pead_watch_signals` 행에 함께 저장한다. 조건 미달·판정 불가 행은 꼬리표가 빈칸이다.
- 판정 기록은 한 번만 쓰므로(INSERT OR IGNORE) 꼬리표도 한 번만 쓴다. 받기 실패로 빈칸이 된 칸은 다음 실행에서 다시 채우지 않는다.
- 모든 꼬리표는 **반응일 d0 장 마감(16:00 동부)까지 알 수 있는 정보만** 쓴다. 늦게 판정된 신호도 같다(d0 뒤 가격 행·d0 16:00 뒤 접수 공시는 보지 않는다).
- 쓰기는 장부와 같이 GitHub Actions 예약 실행만 한다.

## 2. 꼬리표

가격은 장부와 같은 yfinance 분할 반영 일봉(`auto_adjust=False`의 Open·High·Low·Close)이고, d0까지의 행만 쓴다.

| 칸 | 정의 | 빈칸 조건 |
| --- | --- | --- |
| `tag_sma200_above` | d0 종가 > d0 포함 최근 200개 종가 평균이면 1, 아니면 0 | d0 행 없음 · 종가 200개 미만 |
| `tag_sma200_dist` | (d0 종가 ÷ 그 200개 평균 − 1) × 100 (%) | 위와 같음 |
| `tag_hi52` | (d0 종가 ÷ d0 포함 최근 252개 종가 최고 − 1) × 100 (%, 0 이하, 0 = 그날 52주 최고) | d0 행 없음 · 종가 252개 미만 |
| `tag_close_pos` | d0 (종가 − 저가) ÷ (고가 − 저가), 0~1 | 고가 ≤ 저가 · 값 없음 · 종가가 고가·저가 밖 |
| `tag_n202_d0` | EDGAR 전체에서 접수일(file_date)이 **d0**인 8-K(8-K/A 제외) 중 Item 2.02가 있는 서로 다른 회사(CIK) 수 | 검색 실패 |
| `tag_n202_prev` | 같은 방법, 접수일이 **d0 직전 거래일**인 회사 수 (참고 — 장 마감 뒤 발표는 대개 이날 접수, 반응일이 d0) | 검색 실패 |
| `tag_weekday` | d0 요일 (월·화·수·목·금) | — |
| `tag_q_before_close` | 그 회사의 같은 분기 10-Q/10-K가 d0 장 마감 전에 나왔으면 1, 아니면 0 (아래 3절) | 접수 목록 실패 · 같은 날 접수 건 Accepted 실패 |
| `tag_lm_pos` · `tag_lm_neg` · `tag_lm_unc` | 보도자료(EX-99.1) 본문 단어 중 Loughran-McDonald 긍정어·부정어·불확실성 단어 비율 (%, 아래 4절) | 보도자료 없음·받기 실패 |
| `tag_lm_words` | 그 본문 단어 수 | 위와 같음 |
| `tag_errors` | 빈칸이 된 꼬리표와 사유 (짧은 글, 값 정보 없음) | — |

### 2.1 같은 날 8-K 2.02 회사 수

- 출처: EDGAR 전문 검색(`efts.sec.gov/LATEST/search-index`, `forms=8-K`, 접수일 하루 범위). 결과 문서마다 `form`·`items`·`ciks`가 있다. `form = "8-K"`이고 `items`에 `2.02`가 있는 문서의 CIK를 모아 서로 다른 개수를 센다(첨부 문서도 같은 접수 번호라 중복은 CIK로 없앤다).
- 접수 시각(Accepted)은 검색 결과에 없어서 "반응일이 d0인 건"을 정확히 셀 수 없다. 그래서 접수일 = d0 (`tag_n202_d0`)과 접수일 = 직전 거래일(`tag_n202_prev`)을 따로 적는다. 둘을 더하거나 고르지 않는다.
- 같은 날짜 검색 결과는 실행 안에서 한 번만 받는다.

## 3. 같은 분기 10-Q/10-K가 장 마감 전에 나왔는지

- 그 회사 EDGAR submissions 최근 접수 목록에서 form이 `10-Q` 또는 `10-K`(정정 `/A` 제외)이고 접수일이 **그 신호 8-K 접수일 ~ d0** 안인 건을 찾는다(직전 분기 보고서는 이번 실적 8-K보다 먼저 나오므로 이 범위면 같은 분기로 본다).
  - 접수일 < d0인 건이 있으면 1.
  - 접수일 = d0인 건만 있으면 그 공시 색인 페이지 **Accepted**(동부)가 d0 16:00 전이면 1, 아니면 0. (submissions `acceptanceDateTime`은 쓰지 않는다 — 원 사전 등록 3장과 같은 이유.)
  - 없으면 0.
- 보도자료 수치(매출·이익)는 이 꼬리표에 넣지 않는다(무료 XBRL이 없다 — 보완 필터 탐색 F4·F5 결과).

## 4. 보도자료 어조 (Loughran-McDonald)

- 사전: Loughran-McDonald Master Dictionary 공개본(노트르담 SRAF, 1993–2025판, 2026-03 갱신). 원 CSV에서 Positive·Negative·Uncertainty 열이 **양수**(추가 연도)인 단어만 뽑아 `data/lm/lm_sentiment_words.csv`에 둔다. 음수(그 해 삭제)는 뺀다. 출처 URL·원 파일 sha256·뽑은 방법은 `data/lm/SOURCE.md`에 적는다. 사전은 학술 연구 무료 이용 조건이다(상업 이용은 별도 허가 — 이 장부는 개인 기록용).
- 문서: 그 신호 8-K(같은 접수 번호) 색인 페이지의 문서 표에서 Type이 `EX-99.1`인 첫 문서. 없으면 빈칸(다른 첨부로 대신하지 않는다).
- 본문: HTML 태그·스크립트·스타일을 지우고, HTML 엔티티를 풀고, 정규식 `[A-Za-z]+`로 단어를 자른 뒤 대문자로 바꾼다. 단어 수 = 그 개수(사전에 없는 단어 포함, 숫자 제외).
- 비율 = 그 목록에 있는 단어 개수 ÷ 단어 수 × 100. 부정 표현(“not”) 처리·가중치 없음.
- 받기 실패·단어 0개면 빈칸.

## 5. 쓰지 않는 것

- 꼬리표로 신호를 거르거나 순서를 바꾸지 않는다. 편지에 보이지 않는다(기록만).
- 판정(원 사전 등록 7장) 계산에 꼬리표를 넣지 않는다.
