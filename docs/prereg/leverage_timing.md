# 레버리지 비율 조절 1 — 규칙 사전 등록 (시험 5: R1·R2·M1·M2·M3)

> 등록 2026-10-17. 사용자 지시문 원문을 그대로 옮긴 것이다(빠진 부분은 지어내지 않았다).
> 이 문서를 커밋하고 태그 **`leverage-timing-prereg`**를 push한 뒤에만 데이터 확인·성적 계산으로 넘어간다.
> 결과를 본 뒤 규칙을 바꾸지 않는다.

## A. 단계

- 1배 = QQQ 100%, 1.5배 = QQQ 50% + QLD 50%, 2배 = QLD 100%
- 신호가 바뀔 때만 비율을 다시 맞춤
- 현금으로 가지 않음
- TQQQ 사용하지 않음

## B. R1 국면 1.5배

- factory/regimes.py 국면 사용
- 상승장 → 1.5배, 하락장·폭락장 → 1배
- t일 종가 판단 → t+1 종가 체결

## C. R2 국면 2배

B와 같되 상승장 → 2배

## D. M1 금리차

- 매달 마지막 거래일 판단, 다음 거래일 체결
- T10Y2Y ≥ 0 → 1.5배, 아니면 1배
- 1976-06 이전·결측은 GS10 − GS2 월별(월 m 값은 m+1월 1일부터)

## E. M2 금융여건

- NFCI < 0 → 1.5배
- ALFRED 발표본이 있는 기간은 판단일에 공개된 발표본 값
- 발표본이 없는 기간은 현재 값 + "수정값 사용" 표시
- 그런 구간이 판정에 들어가면 M2는 "참고"로 강등

## F. M3 통화량

- M2SL 전년비 증가율 > 6개월 전 전년비 증가율 → 1.5배
- 월 m 값은 m+2월 1일부터

## G. 구간·비용

- S&P500 1977-01~1998-12, 나스닥 종합 1977-01~1998-12 (합성 2배 = 일간 2배 − 연 0.95% − DTB3 차입비용)
- QQQ 2000-01~2021-12 (research/shock-dip의 ^NDX 보정 방식, QLD 2006-06~ 실제)
- R1·R2만 해외 5곳(^N225, ^GDAXI, ^FTSE, ^HSI, ^KS11, 데이터 시작~2021-12, 합성 2배)
- 비용 편도 0.1%
- QQQ 구간 원화 세후(과세연도 통산 − 250만 원 → 22%, DEXKOUS), 나머지 세전
- 2022 이후 사용 금지

## H. 합격 기준(변형마다)

- ① 미국 세 구간 모두 연복리 > 1배 보유
- ② 세 구간 모두 연복리 > 무작위 대조 95백분위
  (레버리지 단계로 보낸 날 비율을 같게 맞춘 무작위 타이밍 1000회. R은 일 단위 구간 길이 분포 유지, M은 월 단위)
- ③ 최대 낙폭이 1배 보유보다 10%p 넘게 깊지 않음
- ④ R1·R2만: 해외 5곳 중 3곳 이상 연복리 > 1배 보유
- 참고 보고(판정 아님): 항상 1.5배·항상 2배, 전략 4 방식(상승 2배·하락 SGOV), 국면별 성적, 전환 횟수, 레버리지 시간 비율
- 시험 수 5. 결과를 본 뒤 규칙 변경 금지
