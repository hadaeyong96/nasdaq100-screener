# 실적급등 매도 조건 비교 (pead_exits) — 사전 등록

- 작성 2026-11-13, 브랜치 `feature/pead-exits`. 이 문서와 `configs/pead_exits.yaml`을 커밋한 곳에 태그 `pead-exits-prereg`. **이후 수정 금지.**
- 앞으로 기록하는 가상 장부다. 실제 돈·주문은 없다.
- 코드보다 먼저 커밋한다. 구현하다가 이 문서와 다르게 해석한 부분이 생기면 이 문서는 고치지 않는다. 대신 첫 정규 실행 전에 `docs/prereg/pead_exits_impl.md`에 따로 적는다.
- **V1.0(`pead-watch-prereg`, `docs/prereg/pead_watch.md`)의 규칙은 하나도 바꾸지 않는다.** 신호·매수·주 장부(90)·비교 장부(60)·참고 장부(20)·12개월 판정·아침 편지 모두 그대로다. 이 문서는 같은 신호와 같은 매수에 **파는 날만 다른** 가상 장부 2개(조건 A·B)를 더한다.

## 1. 장부

| 장부 | 매수 | 매도 |
| --- | --- | --- |
| 기준 V1 (주 장부, 기존 그대로) | 반응일 다음 거래일 시가 | 매수일부터 90거래일째 종가 |
| 조건 A (발표 전 매도) | 같음 | 다음 실적 발표 예정일의 2거래일 전 종가. 최소 5거래일, 최대 90거래일 |
| 조건 B (목표 수익 매도) | 같음 | 종가가 매수가 × 1.20 이상이 된 날의 다음 거래일 시가. 90거래일 안에 못 닿으면 90거래일째 종가 |

- 신호, 대상 명단, 실적 발표 판정, 반응일, 매수일·매수가, 가격 자료(yfinance `auto_adjust=False`), 비용, 세금, 환율은 모두 V1.0 그대로다.
- 손절은 없다.
- **시작일**: 이 문서가 main에 병합된 뒤 첫 정규 실행(GitHub Actions 예약 실행)의 기준일. 그 실행이 가상 장부 DB에 고정하고 이후 바꾸지 않는다.
  - 반응일이 시작일 이상인 신호만 A·B에 넣는다.
  - 그보다 앞선 신호(CRWV 2026-11-11 등)는 A·B에 넣지 않는다.
- 같은 종목 겹침은 장부마다 따로 본다. V1과 같은 규칙으로, 앞 신호 반응일 ≤ 새 반응일 < 앞 매매 매도일(보유·대기 중이면 예정 매도일)이면 무시한다.
  - B가 일찍 팔았으면 그 뒤 같은 종목 신호는 B에만 들어갈 수 있다. 짝 비교는 3절처럼 양쪽에 다 있는 신호만 쓴다.
- 매수일 시가가 없으면 '가격 공백'으로 매매 안 됨(V1과 같음).

### 1-1. 조건 A — 다음 실적 발표 예정일

- **예정일(E)**: yfinance `Ticker.get_earnings_dates(limit=12)`의 날짜 중 **반응일 + 30달력일 이후의 첫 날짜**.
  - 30일 조건은 방금 한 발표가 하루 어긋난 날짜로 남아 있는 경우를 빼기 위한 것이다.
- **받는 때**: 그 신호를 처음 기록하는 실행(반응일 종가 뒤, 매수일 시가 전).
  - 받은 날짜(E), 출처, 받은 실행의 기준일과 한국 날짜를 저장한다.
  - **이후 예정일이 바뀌어도 처음 저장한 값을 쓴다.** 매도 예정일도 처음 정한 날 그대로다.
  - 실행이 빠져 늦게 판정된 신호는 판정한 실행에서 받는다(그때 알 수 있는 값).
- **못 받으면 (8-K 간격 추정)**:
  - V1.0 3장 규칙(8-K 2.02, 직전 센 발표에서 60일 이상)으로 그 회사의 발표를 센다.
  - 이번 발표와 그 앞의 발표 최대 4건의 반응일(색인 Accepted로 V1.0 규칙대로)을 구한다.
  - 이웃한 반응일 사이 달력일 간격(최대 4개, 최소 1개)의 평균을 반올림하고, 이번 반응일에 더해 E로 삼는다.
  - 출처 = `8-K 간격 추정(간격 n개)`.
- **그것도 없으면**: 매수일부터 60거래일째 종가에 판다. 출처 = `기본 60일`.
- **매도 위치**: j = (E 이상인 첫 거래일 위치) − 2. 곧 E 전 2번째 거래일이고, E가 휴장일이어도 같은 식이다.
  - 최소 5거래일, 최대 90거래일로 자른다: j = min(max(j, 매수 위치 + 5), 매수 위치 + 90).
  - 그날 종가에 판다.
  - 그날 그 종목 행이 없으면 매수일 ~ 예정일 사이 마지막 종가에 판다(V1과 같음).

### 1-2. 조건 B — 목표 수익

- 목표가 = 매수가 × 1.20 (달러, 비용 전).
- 판정은 **종가만** 쓴다. 장중 고가는 쓰지 않는다.
  - 매수일부터 89거래일째까지 그 종목 종가(실제 행만)가 목표가 이상이 된 첫날을 k로 둔다. 매수일 종가도 센다.
  - k 다음 거래일부터 90거래일째까지 시가가 있는 첫날, 그 **시가**에 판다.
  - 그 사이 시가가 하나도 없으면 90거래일째까지 마지막 종가에 판다.
- 목표에 못 닿으면 90거래일째 종가에 판다(V1과 같은 매도).
- 기록: 목표가, 목표 도달일 k(없으면 빈칸), 도달까지 걸린 거래일 수, 매도 방식(목표 / 90일).

### 1-3. 가이던스 상향 꼬리표 (정의 고정)

- 글: 어조 꼬리표와 같은 보도자료(EX-99.1, 보강 규칙 포함).
  - 스크립트·스타일·태그를 지우고 엔티티를 푼 뒤 소문자로 바꾼다.
  - `[.!?;]` 뒤 공백에서 문장을 나눈다. 문장 안 단어 = `[a-z]+`.
- 동사 V = raise, raises, raised, raising, increase, increases, increased, increasing.
- 다음 중 하나라도 맞는 문장이 있으면 **1**:
  1. V 뒤 8단어 안에 guidance, outlook, outlooks, forecast, forecasts.
  2. V 뒤 4단어 안에 "full year", "fiscal year", annual, fy 중 하나가 있고, 그 뒤 6단어 안에 guidance, outlook, outlooks, forecast, forecasts, expectations, target, targets, range.
- 다만 V 바로 앞 3단어 안에 not, no, never, without이 있으면 그 V는 세지 않는다.
- 보도자료가 있고 단어가 1개 이상인데 맞는 문장이 없으면 **0**. 보도자료가 없거나 받기에 실패하면 빈칸(사유 기록).
- 처음 맞은 문장(앞 200자)을 함께 저장한다.

## 2. 비용·세금·초과

- 비용: 매수·매도 수수료 0.07%씩, 환전 0.1%씩. V1과 같고 `core/sw1.krw_after_cost`를 쓴다.
- 세금: 장부마다 매도 연도별 순이익의 22%를 이익 난 매매에 이익 비례로 나눈다. 공제는 없다. `core/sw1.ledger_tax`를 쓴다.
- 초과 = 신호 종목 − 같은 매수일 시가에 사서 **같은 매도일·같은 때**에 판 QQQ. 원화, 비용 뒤.
  - B가 목표로 시가에 팔면 QQQ도 그날 시가에 판다.
- 60거래일 비교 장부·20거래일 참고 장부는 그대로 기록한다(이 비교에는 쓰지 않음).

## 3. 주 비교 (2개, Holm 보정)

- ① A vs V1, ② B vs V1.
- **짝**: 반응일이 시작일 이상이고, 두 장부 모두에 끝난 매매가 있는 신호(종목, 반응일).
- 신호마다 d = (조건 장부 초과) − (V1 초과). 원화, 비용 뒤, **세전**.
  - 세금은 장부 전체로 정해지므로 짝 차이에서 빼고, 세후 비교는 5절 보고로 따로 낸다.
- **묶음**: 같은 종목이거나 같은 반응일인 신호는 한 묶음이다(서로 이어지면 같은 묶음, 연결 요소).
- **p값**: 묶음 단위 부호 뒤집기, 10,000회, 시드 20261113, 양쪽.
  - 묶음마다 d 합의 부호를 ±로 뒤집은 평균의 절댓값이 실제 평균의 절댓값 이상인 비율로 계산한다.
- **Holm**(유의수준 0.05)으로 ①·② 두 p값을 보정한다.
- 조건이 V1보다 **낫다** = 보정 뒤 유의하고 평균 d > 0. **못하다** = 보정 뒤 유의하고 평균 d < 0. 그 밖은 **차이 없음**.

## 4. 분석 (주 비교 아님, 판단에 쓰지 않음)

대상: V1(주 장부) 매매 중 반응일이 시작일 이상이고 끝난 것. 값은 매매 초과(원화, 비용 뒤, 세전).

- **200일선 분석**: "반응일 전날 종가 < 반응일 전날까지 종가 200개 평균"인 신호와 나머지를 비교한다.
  - 평균 차이와 p값을 낸다. p값은 매매 단위 꼬리표 섞기 10,000회, 시드 20261113, 양쪽이다.
  - 보정은 하지 않고, 이 한 개만 이름 붙여 본다.
- **탐색 꼬리표** (기준값 고정). 꼬리표 정의는 `docs/prereg/pead_watch_tags.md`(+ 보강)를 따르고, 가이던스만 아래에서 새로 정한다.

  | 꼬리표 | 구간 | 연속형 |
  | --- | --- | --- |
  | 200일선 이격도 % (`tag_sma200_dist`) | x ≤ −10 / −10 < x ≤ 0 / 0 < x ≤ 10 / x > 10 | 예 |
  | 52주 최고가 대비 % (`tag_hi52`) | −5 < x ≤ 0 / −15 < x ≤ −5 / −30 < x ≤ −15 / x ≤ −30 | 예 |
  | 종가 위치 (`tag_close_pos`) | x < 0.25 / 0.25 ≤ x ≤ 0.75 / x > 0.75 | 예 |
  | 같은 날 발표 수 (`tag_n202_d0`) | ≤ 1 / 2~3 / ≥ 4 | 예 |
  | 10-Q 동시 제출 (`tag_q_before_close`) | 예 / 아니오 | |
  | 요일 (`tag_weekday`) | 월·화·수·목·금 | |
  | 어조 = `tag_lm_pos − tag_lm_neg` | 표본 중앙값 초과 / 이하 | |
  | 가이던스 상향 (1-3절) | 예 / 아니오 | |

  - 구간마다 "그 구간 vs 나머지" 평균 차이의 p값을 낸다(매매 단위 섞기 10,000회, 시드 20261113, 양쪽). 두 구간짜리 꼬리표는 검정 1개다.
  - 매매 5건 미만인 구간은 검정하지 않는다(표본 부족). 꼬리표가 빈칸인 매매는 그 꼬리표에서 뺀다.
  - 모든 검정을 한 묶음으로 **Benjamini-Hochberg FDR 10%** 처리한다.
  - **연속형**은 구간 평균이 순서대로 단조(증가 또는 감소)가 아니면 BH 결과와 상관없이 **우연**으로 본다.
- A·B 장부의 같은 표는 숫자만 참고로 낸다(검정 없음).

## 5. 보고 지표

장부(V1·A·B)마다 반응일이 시작일 이상이고 끝난 매매로 낸다.

- 평균 초과, 중앙값, 승률(초과 > 0 비율), 상위 10% 종목을 뺀 평균(초과 큰 순 상위 ⌈10%⌉건 제외), 최대 손실(가장 나쁜 매매 초과).
- 평균의 95% 구간: 3절 묶음 단위 복원 추출, 10,000회, 시드 20261113, 2.5·97.5 백분위수.
- B: 목표 도달 비율, 도달까지 걸린 거래일 수(중앙값·평균).
- 짝 비교 ①·②: 평균 d, 중앙값 d, 95% 구간(묶음 복원 추출), p값, Holm 보정 p값.
- 세전과 세후(장부 세금 뒤)를 나눠서 낸다.
- 포트폴리오 누적(6절): V1·A·B 각 평가액, QQQ 100% 대비, 최대 낙폭.

## 6. 15칸 포트폴리오 (참고 기록)

- V1·A·B 각각 따로 둔다. 가상 1억 원에서 시작한다.
  - 시작일 시가에 시작일 환율(스프레드 0.1% 뒤)로 달러로 바꾸고, 전부 QQQ로 간주한다.
  - 기존 "남은 현금 1/10" 포트폴리오 기록(`pead_watch_portfolio`)은 그대로 둔다.
- 칸 15개. 매수일 시가에 산다.
  - 칸당 예산 = 그때 남은 현금(QQQ, 그날 시가 평가) ÷ 빈 칸 수. 곧 처음에는 1/15이다.
  - 수수료 0.07%. 정수 주만 사고, 최소 100만 원(시작 환율로 달러 고정)이다.
- 칸이 다 찼으면 새 매매는 사지 않고 '15칸 다 참'으로 건너뜀 기록을 남긴다.
- 판 돈은 QQQ로 돌아간다. 종가 매도는 그날 QQQ 종가로, B의 시가 매도는 그날 QQQ 시가로 바꾼다.
  - 같은 날에는 시가 매도 → 시가 매수 → 종가 매도 순서로 처리한다.
- 대상: 각 장부에서 반응일이 시작일 이상인 매매. V1 15칸도 같은 신호 범위만 쓰므로 CRWV는 들어가지 않는다.
- 같은 날 매수는 종목 기호 순이다.

## 7. 성적 시점

- **첫 성적**: A·B 모두 끝난 매매가 50건 이상이 된 뒤 첫 실행 때 계산한다. 중간 성적이고 판단하지 않는다.
- **확정 판단**: A·B 모두 끝난 매매가 120건 이상이 된 뒤 첫 실행 때 계산한다. 3절 판정을 낸다.
  - 이긴 조건으로 편지 기준을 바꿀지는 **사용자가 정한다**(자동 전환 없음).
- 중간에 숫자를 보는 것은 된다. **규칙은 바꾸지 않는다.**
- V1.0의 원래 12개월 판정(`docs/prereg/pead_watch.md` 7장)은 그대로 실행한다.
