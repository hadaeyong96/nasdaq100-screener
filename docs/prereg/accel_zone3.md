## 1. 신호 규칙 (작업 6 사전 등록, 판정·장부·브리핑 공통, `core/accel.py`)

- RS선 = 종목 종가 ÷ QQQ 종가 (날짜는 QQQ 거래일 기준)
- 최근 힘 = RS(t)/RS(t−20) − 1, 직전 힘 = RS(t−20)/RS(t−40) − 1, 점수 = 최근 힘 − 직전 힘
- 대상: 60거래일 이상 가격(t−59일 종가가 있고 t−40·t−20·t 종가가 있음). **[결정 1] 구역 ③ 판정에서는 5달러 조건을 뺀다**
  (S&P 500 편입이 저가 소형주를 이미 거르고, 과거 실제 가격에는 이후 분할 정보가 필요해 공정하게 적용할 수 없음. 장부·브리핑은 유지)
- 점수 상위 10, 같은 비중. **20거래일마다 교체**, 신호일 종가 → 다음 거래일 종가 체결, 남는 종목은 비중 차이만, 쉬는 돈 없음

## 3. 대상·데이터 처리 (RS26과 똑같이 적용 — `docs/prereg/rs26_zone3.md` 1장)

- S&P 100: 신호일이 속한 달의 명단(그달 말 판 ∪ 그달 말 뒤 처음 새로 고쳐진 판) **∪ 전달 말 판**(달 중간 신호라 앞뒤 모두 빼는 쪽)
- 가격 공백 63종목 제외(생존 편향 TRUE, 방향 불명), 분할 점검 제외 3종목 HSH·WYND·EP, Tiingo 분할 반영
- 확보율(전체 종목×신호, 점수에 필요한 t−59·t−40·t−20·t와 체결일 종가가 모두 있는 비율) 계산 전 집계:

## 4. 비교·합격 기준 (RS26과 같은 6개, 비용 0.1%, 반올림 전 값)

비교: QQQ(첫 체결일 2012-01-04 종가에 사서 보유), 구역 EW(그 신호일 대상 전 종목 같은 비중, 같은 주기), 무작위(그 신호일 대상에서 10종목,
1,000회, 시드 20261015 + i). 연복리는 2012-01-03 ~ 2021-12-31 끝 청산·세금 뒤.

1. 세후 연복리 > QQQ
2. 세후 연복리 > 구역 EW
3. 무작위 1,000회 분포에서 99백분위 이상(p ≤ 0.01)
4. 한 번 이어 돈 일별 곡선을 잘라 2012-01-03 ~ 2016-12-30, 2016-12-30 ~ 2021-12-31 두 구간 모두 QQQ 대비 연복리 초과 > 0 (다시 시작하지 않음)
5. 같은 곡선 달력 연도 10개 중 6개 이상 QQQ 초과 > 0
6. 최대 낙폭 − QQQ 최대 낙폭 ≥ −15%p
