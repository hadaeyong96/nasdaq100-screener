# P6-1 지시문 — 포트폴리오 엔진 + 1999~2021 종목 없는 조합 (P0·P3·P4·P5)

---

P5를 마무리했어. 결론: 신호 전략(B0.5)은 2016~2021년 QQQ 대비 +0.01%p, 무작위 진입 48백분위라 종목 선택 우위가 확인되지 않았고, 수익의 대부분은 QQQM에서, 손실 요인은 QQQM 반복 매매의 세금·비용이었어. 이제 **포트폴리오 운영(P6)** 을 연구한다. `docs/p6_plan.md`를 먼저 읽고 따를 것. 검증 구간(2022년~)은 계속 봉인. 결과가 나빠도 그대로 보고해.

## 0. 사전 등록 (결과 계산 전에 먼저)

- `docs/p6_plan.md` 4장(P0·P3·P4·P5와 주변값)과 5장(판정 기준 두 등급, 공통 조건)을 `configs/p6_1_preregistration.yaml`에 옮겨 적고, **어떤 백테스트도 돌리기 전에** 커밋해 (메시지 "P6-1 preregistration").
- 목표 등급 칸은 `target_tier: undecided`로 두고, 사용자가 실행 전에 정하면 그 값으로 바꿔서 같은 커밋에 넣어. 결과를 본 뒤에는 이 파일 수정 금지.

## 1. 데이터

1. QQQ 1999-03-10 ~ 2021-12-31 일봉과 배당 (auto_adjust=False, 배당은 따로).
2. FRED `DTB3` → 일별 단기 국채 수익. 휴일 처리와 연율→일율 변환 방식을 보고.
3. QLD: 2006-06 이후 실제 데이터. 이전은 `QQQ 일간 수익 × 2 − 연 0.95%/252 − DTB3 일율`로 합성. 2006-06 ~ 2021-12 겹치는 기간의 **연 수익률 차이와 추적 오차**를 보고 (합성이 실제보다 좋게 나오면 표시).
4. 환율: P5-5의 `merge_fx_with_fallback` 재사용, 1999년부터.
5. 원화 기준 초기 자금 4,000만 원. 첫날 1회 환전.

## 2. 포트폴리오 엔진 (`engine/portfolio.py`, 신규)

- 자산 여러 개(QQQM, 단기 국채, QLD, 현금)를 비중·규칙으로 운용하는 일별 시뮬레이터.
- 거래 체결: 신호 다음 날 시가 (국채는 다음 날 기준 수익부터 적용).
- **이동평균법 취득가**, 연간 실현 손익 합산 → 250만 원 공제 후 22%, 다음 해 5월에 원화로 납부(납부 시 환전 스프레드 0.1%), 배당 원천징수 15% 후 재투자, 수수료 0.07%.
- 세후 (a)·(b), MDD, **원금 회복 기간**(최고점 회복까지 거래일 수, 최장값), 최악의 해·월, 샤프, 세금 합계, 매매 횟수.
- P5의 `engine/backtest.py`는 건드리지 말 것 (위성 조합은 P6-2에서 연결).
- 테스트: 100% 보유는 매매 0회·세금은 (a) 청산 시에만, 재조정 시 이동평균 취득가 계산, 연 250만 원 공제 경계값, 합성 QLD 계산식, 국채 일일 수익.

## 3. 실행

| 후보 | 규칙 |
| --- | --- |
| P0 | QQQM 100% 보유 |
| P3 | 코어 60% + 대기 40%(단기 국채). QQQ 종가가 직전 최고점 대비 −20/−30/−40%에 처음 도달할 때마다 대기 자금의 1/3씩 코어로. QQQ가 직전 최고점을 회복하면 60:40으로 한 번 재조정 |
| P4 | QQQ 종가가 200일 단순이동평균 아래면 다음 날 코어의 40%를 단기 국채로, 위로 돌아오면 다음 날 다시 코어로 |
| P5 | P3 + 대기 자금 투입 후 QQQ가 200일선을 다시 넘으면 총자산의 최대 20%를 QLD로 (재원은 남은 대기 자금 → 부족하면 코어). QQQ가 200일선을 다시 깨거나 직전 최고점을 회복하면 QLD 청산 후 코어로 |

- 주변값: P3·P5 투입 단계 −15/−25/−35, −20/−30/−40(주), −25/−35/−45 / P4·P5 이동평균 190·200(주)·210일.
- 구간: 1999-03 ~ 2021-12 전체, 하위 구간 1999~2007 · 2008~2015 · 2016~2021 각각 (하위 구간은 해당 구간 시작일에 4,000만 원으로 새로 시작).
- **재현 확인**: P0의 2015~2021 세후 (a)·(b)·MDD가 P5의 QQQ 값(20.60% · 23.62% · −27.31%)과 맞는지. 다르면 원인 설명.
