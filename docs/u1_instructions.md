# U1 지시문 — 투자 자금을 사용자가 직접 설정

---

사용자 혼자 쓰는 프로그램이다. 목표는 **투자 자금을 전략 설정(config.yaml)과 분리해서, 처음 시작할 때와 필요할 때 명령 하나로 설정**하게 만드는 것. 전략·백테스트 결과는 바뀌면 안 된다.

**선행 조건**: "Sizing base audit and fix"가 커밋된 뒤 시작한다. 커밋 전이면 먼저 알려줘.

## 1. 사용자 설정 파일

- `user_settings.yaml` (프로젝트 루트) — 사용자가 바꾸는 값만:
  ```yaml
  capital_krw: 40000000     # 투자 자금(원)
  set_on: 2026-09-28        # 마지막 설정일
  ```
- `.gitignore`에 추가 (개인 자금 정보). 대신 `user_settings.example.yaml`을 커밋.
- 처음 한 번은 현재 값 **40,000,000원**으로 옮겨 만든다.
- `config.yaml`의 `account.total_krw`는 삭제하고, 자리에 "투자 자금은 user_settings.yaml에서 설정" 주석만 남긴다.

## 2. 설정 명령

`python -m tools.set_capital`

- 현재 자금과 설정일을 보여주고 새 금액을 묻는다. 입력은 **만원 단위** (예: `4000` → 4,000만 원). 쉼표 허용.
- 확인 질문: "투자 자금을 4,000만 원 → 5,000만 원으로 바꿀까요? (y/n)"
- 입력 검사: 100만 원 미만이거나 100억 원 초과면 거부. 숫자가 아니면 다시 묻기.
- 저장 후, 최근 신호 종목 가격 기준으로 **"이 자금으로 1주도 못 사는 종목 수"** 를 알려준다 (참고용).
- 비대화식 옵션: `python -m tools.set_capital --amount 5000` (만원 단위, 확인 생략은 `--yes`).
- 변경 기록: `data/capital_history.csv`에 한 줄 추가 (날짜, 이전, 이후, 사유). 사유는 선택 입력 (입금/출금/재설정).

## 3. 처음 실행할 때

- `user_settings.yaml`이 없는 상태에서 `engine.daily`를 **터미널에서 직접** 실행하면 → 설정 명령을 자동으로 띄운다.
- **자동 실행(작업 스케줄러)** 중에 없으면 → 묻지 않는다. 보고서를 보내지 않고, 로그에 남기고, 운영 알림으로 "투자 자금이 설정되지 않았습니다. `python -m tools.set_capital`을 실행하세요"를 보낸다.

## 4. 코드 구조 (핵심)

- 수량 계산 함수(`core/sizing.py` 등)는 **자금을 인자로 직접 받는다** (`capital_krw`). 설정 파일을 스스로 읽지 않는다.
- 실전·모의(`engine.daily`) → `user_settings.yaml`의 값을 넘긴다.
- 백테스트 → `backtest.total_krw`를 넘긴다. **백테스트 코드는 user_settings.yaml을 절대 읽지 않는다** (테스트로 확인).
- 이렇게 되면 사이징 점검 때 넣은 "두 자금이 같아야 한다" 안전장치는 필요 없으므로, **"백테스트가 사용자 자금을 쓰지 않는다"는 테스트로 대체**한다.
- 자금을 바꿔도 **이미 보유 중인 포지션 수량은 바꾸지 않는다.** 새 추천부터 적용.

## 6. 테스트와 확인

- 설정 명령: 만원 단위 변환, 쉼표, 범위 밖 거부, 확인 n이면 저장 안 함, 기록 파일 추가
- 설정 파일 없음: 터미널 실행 시 안내, 자동 실행 시 보고서 미발송 + 운영 알림
- 백테스트가 user_settings.yaml을 읽지 않음 (파일 값을 바꿔도 백테스트 결과 동일)
- **회귀 확인**: 사이징 점검에서 나온 수정된 B0.5 결과가 그대로 재현되는지, 9/25 실전 추천 수량이 4,000만 원 기준 값(BKNG 1주 등)과 같은지
- `pytest` 전부 통과
- `.env` 값은 출력하지 않는다. 프로젝트 밖 파일은 읽지 않는다.
