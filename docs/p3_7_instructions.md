# P3.7 지시문 — 일일 보고서에 초보자용 "선별 이유" 설명 추가

---

보고서만 읽어도 **어떤 지표·설정 때문에 이 종목이 선별(또는 매도·제외)됐는지** 초보자가 이해할 수 있게 만들어줘. `docs/report_template.html`의 배치·문구·스크립트를 그대로 따를 것. 전략 로직과 숫자는 바꾸지 않는다. 표시만 추가하는 작업이야.

## 0. 작업 범위 (중요)

- P5-4 계산이 백그라운드에서 돌고 있을 수 있어. **`engine/backtest.py`, `scripts/p5_4*`, `configs/p5_*`, `outputs/backtest/`는 건드리지 마.**
- 이번 작업 파일만 따로 커밋해 (P5-4 파일과 섞지 말 것).
- 텔레그램 글은 변경 없음.

## 1. 설명 문구 모듈 `core/explain.py`

- 신호·청산·제외·경고의 **사유 코드마다** 쉬운 설명을 만드는 함수 하나로 모은다. 보고서 코드 곳곳에 문장을 흩어 쓰지 말 것.
- 출력 구조: `title`(예: "펩시코 · 1차 정찰 매수"), `badge`(예: "슬롯의 1/9"), `checks`(목록, 각 항목은 `y`=충족 / `n`=미충족·감점 / `i`=참고), `body`(쉬운 설명 2~3문장), `next`(다음 단계, 없으면 생략).
- **실제 그날의 지표 값**을 넣는다 (RSI 전날→오늘, MACD − 신호선, 구름 상단·하단, 후행스팬, 거래량 배수, 손절가, 만료일 등).
- 숫자 기준(30/50/70, 10거래일, 쿨다운 5일, 위험 2%·1%, 1:2:6 비중, 지표 기간)은 **config에서 읽어** 문장에 넣는다. 설정이 바뀌면 설명도 따라 바뀌어야 해.
- 문체: 템플릿처럼 쉬운 존댓말("~해요"), 전문 용어는 처음 나올 때 괄호로 풀이.
- 대상 코드 (현재 엔진에 있는 코드 전부):
  - 매수: 1차(A1), 2차(A2), 3차(A3), 재진입(B)
  - 매도: 손절, E1, E2, E3, 1차 만료, (있다면) ATR_TRAIL
  - 제외: 실적 임박, 과열, 잦은 교차, 보유 한도, 자금 한도, 쿨다운, (있다면) C2 등 새 필터
  - 경고: 목표 도달, 기준선 이탈, 손절 근접 등 현재 경고 전부
  - 관찰: 2차 대기(골든크로스까지 남은 간격), 3차 대기(4조건 중 몇 개 충족)
- 점수: 템플릿의 점수 설명은 예시야. **실제 점수 계산 항목을 코드에서 확인해서** 체크 목록과 용어 사전에 정확히 적어줘 (예: 거래량 배수, 손절폭 등 실제 쓰는 항목만).

## 2. 보고서 표시

- 신규 매수(전체·1차·2차·3차·재진입), 매도·손절, 관찰 목록, 걸러진 신호, 경고 표 맨 끝에 **"설명" 칸**과 `왜?` 버튼을 넣는다. 보유 현황 표는 이번엔 제외.
- 각 종목 줄 바로 아래에 `tr.why` 설명 줄(처음엔 접힘)을 넣고, `colspan`은 그 표의 칸 수와 같게. 빈 표의 colspan도 1씩 늘린다.
- 탭 아래 안내줄: "각 줄 끝의 왜?를 누르면…" · **모든 설명 펼치기/접기** 버튼 · "처음이라면 → 읽는 법" 바로가기.
- 머리글 정렬 시 설명 줄이 **자기 종목 줄과 함께** 움직여야 한다 (템플릿 스크립트 그대로).
- 휴대폰 카드 보기에서 설명 줄은 카드 아래에 펼쳐진다 (템플릿 CSS 그대로).
- 금액 재계산(`tr.sig`)은 설명 줄 추가 후에도 그대로 동작해야 한다.

## 3. "읽는 법" 탭 (새 탭, 규칙 탭 다음)

템플릿 내용 그대로: 보고서 읽는 순서 4단계 / 지표 4가지 카드(RSI·MACD·일목 구름·손절가) / 사는 순서 1:2:6 흐름 + 재진입 / 파는 순서 손절·E1·E2·E3 + 만료·쿨다운 / 사지 않는 경우 / 용어 사전. 숫자는 1장처럼 config 값으로 채운다.

## 4. 테스트

- 엔진이 낼 수 있는 **모든 사유 코드에 설명이 있는지** (설명 없는 코드가 생기면 테스트 실패 → 앞으로 새 규칙을 추가할 때 설명을 빠뜨리지 않게)
- 설명에 실제 지표 값이 들어가는지 (샘플 신호로 RSI 값·손절가 문자열 확인)
- config 값을 바꾸면 설명 숫자도 바뀌는지 (예: RSI 기준 30 → 25)
- 설명 줄 colspan = 표 칸 수, 설명 줄 수 = 종목 줄 수
- 정렬 후 설명 줄이 자기 종목 바로 아래에 있는지 (가능하면 playwright로)
- `pytest` 전부 통과

## 5. 확인과 발송

- 실전 모드 보고서를 상태 재처리 없이 다시 만들고 PC 화면·휴대폰 폭(390px) 캡처로 확인
- `--resend`로 발송 (토큰 값 출력 금지)
